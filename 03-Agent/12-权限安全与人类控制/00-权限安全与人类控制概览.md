# 权限、安全与人类控制概览

> [!summary]
> Agent 的安全重点不是要求模型永远判断正确，而是让每个动作受到最小权限、阶段能力、参数校验、隔离环境和人工审批的共同限制。

## 动作授权链

```text
模型提出动作
→ 当前阶段是否允许
→ 当前身份是否有权限
→ 参数和目标是否在 Scope 内
→ 是否需要人工 Approval
→ 在受限环境执行
→ 记录结果和审计事件
```

## 本专题要解决的问题

- 权限（Permission）、阶段能力（Capability）、策略（Policy）、沙箱（Sandbox）和人工批准（Approval）有什么区别；
- 只读、可逆、破坏性和外部发布动作怎样分级；
- Prompt Injection 为什么会通过工具扩大影响；
- Secrets、个人信息和业务数据怎样进入最小必要上下文；
- 用户确认应该确认什么，而不是频繁弹出无意义询问；
- Kill Switch、取消和人工接管怎样实现；
- 为什么 Sandbox 只是纵深防御，不是唯一安全边界。

## 关键边界

模型不能因为“任务需要”自行扩大权限。权限来自系统策略和用户授权，而不是来自 Prompt 中的文字声明。
