# Agent 模块大纲

## 模块定位

研究如何把 LLM 组织成能够围绕目标持续观察、决策、行动和修正的系统。

## 核心问题

> 怎样让一个概率生成模型在真实环境中可靠地完成跨步骤任务？

## 内容结构

1. LLM、Workflow 与 Agent 的区别
2. Agent 的基本循环：观察、决策、行动、反馈
3. 目标、任务与成功标准
4. 状态与上下文
5. 工具调用
6. 任务分解与规划
7. 记忆
8. 环境反馈与错误恢复
9. 反思、Critic 与 Verifier
10. 单 Agent 与多 Agent
11. 权限、边界与可逆性
12. 可靠性、评测与审计
13. 常见架构模式
14. Agent 的能力上限与失败模式

## 模块完成标准

- 能明确指出系统中的模型部分和非模型部分；
- 能画出一个 Agent 的状态与反馈循环；
- 能区分规划、执行、验证和记忆；
- 能判断某项任务是否真的需要 Agent。
