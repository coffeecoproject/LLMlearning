# 独立采样与 Self-Consistency

> [!summary]
> Independent Sampling 是让模型从同一问题独立生成多次；Self-Consistency 再根据多条推理路径最终答案的一致程度进行选择。

## 为什么相同问题能得到不同答案

模型输出的是下一个 Token 的概率分布。采样时不一定每次都选择完全相同的 Token，因此相同上下文可以产生不同后缀。

```text
同一个问题 P
├── 采样 1 → 路径 A
├── 采样 2 → 路径 B
└── 采样 3 → 路径 C
```

这不是模型修改了 Weight，而是运行阶段从概率分布中选择了不同路径。

## 一个最小例子

五次独立生成得到：

```text
A：408
B：408
C：398
D：408
E：408
```

Self-Consistency 可以选择出现次数最多的 `408`。

它利用的是：如果不同推理路径独立到达同一答案，这个答案可能比偶然出现一次的结果更可靠。

## 为什么通常要独立生成

如果让一次回答依次写五个答案，后面的答案能看到前面的答案，容易形成跟随和重复。

独立采样则尽量保持：

```text
每条路径都从同一原始问题开始
→ 不读取其他候选的后缀
```

## 一致不等于正确

模型的多条路径可能共享同一个错误，例如误解了题目或使用了同一错误知识。此时：

```text
错误答案获得多数票
→ Self-Consistency 仍然会选错
```

所以“一致性选择”不是外部事实验证。

## 什么时候适合使用

- 最终答案可以归一化比较，例如数学结果、选项或短代码输出；
- 单次生成具有明显随机波动；
- 多次调用的成本可以接受；
- 正确路径可能以较高概率重复出现。

开放性写作没有唯一答案时，“多数一致”通常意义较弱。

## 它与 CoT 的关系

Self-Consistency 原始方法从多条 CoT 路径中对最终答案做一致性选择。但系统也可以只保存最终答案，不把完整 CoT 展示给用户。

## 常见误解

> [!warning] 误解：采样次数越多，正确率一定持续提高
> 如果模型的错误高度相关，更多采样可能只会重复同一个错误，同时增加成本。

> [!warning] 误解：多数票就是验证
> 多数票比较的是候选之间的一致性；计算器、测试或数据库查询才提供独立证据。
