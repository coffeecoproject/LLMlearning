# 停止、恢复与流式输出概览

> [!summary]
> 每轮选择 Token 后，生成控制器检查是否满足停止条件；最终或过程中，Tokenizer Decode 把 Token ID 恢复成文本，服务层再决定怎样把文本片段发送给用户。

## 阅读顺序

1. [[01-生成循环怎样停止|生成循环怎样停止]]；
2. [[02-Token怎样恢复成文本|Token 怎样恢复成文本]]；
3. [[03-Streaming为什么逐步显示|Streaming 为什么逐步显示]]。

## 三个环节的边界

```text
停止条件：决定还要不要继续生成
Tokenizer Decode：把 Token ID 恢复为字节或文字
Streaming：决定结果以什么节奏传给客户端
```

它们相邻发生，但不是一个动作。
