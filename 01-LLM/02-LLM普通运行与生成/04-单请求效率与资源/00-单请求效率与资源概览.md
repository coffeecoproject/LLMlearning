# 单请求效率与资源概览

> [!summary]
> 单个请求的等待时间和资源占用主要受模型大小、输入长度、输出长度、KV Cache、硬件和实现共同影响；不能只用“参数量”解释全部性能。

## 本专题只看单请求

计划依次解释：

1. 输入长度为什么主要影响 Prefill；
2. 输出长度为什么直接增加 Decode 轮数；
3. TTFT（首 Token 延迟）和 TPOT（每个输出 Token 时间）；
4. 模型权重、临时激活与 KV Cache 分别占用什么资源；
5. 为什么“单请求延迟”和“服务总吞吐量”不是同一个指标。

Batch、Continuous Batching、跨请求调度和多机并行留给下一专题。
