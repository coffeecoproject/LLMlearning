# 输入准备概览

> [!summary]
> 用户界面中的“消息”不能直接进入 Transformer；系统需要先把消息角色和内容整理成模型约定的序列，再由 Tokenizer 变成输入张量。

## 两步不要混在一起

```text
第一步：消息协议整理
Messages → Chat Template → 模型约定格式的序列

第二步：文本离散化
格式化序列 → Tokenizer → input_ids 等输入
```

某些软件会用一个函数连续完成两步，但概念职责仍然不同。

## 阅读顺序

1. [[01-Prompt-Messages与Chat-Template|Prompt、Messages 与 Chat Template]]；
2. [[02-Tokenizer与模型输入张量|Tokenizer 与模型输入张量]]。

## 为什么不能直接把用户文字交给模型

聊天模型不仅需要看见内容，还需要分辨“谁说了什么”和“现在该由谁继续”。Chat Template 负责加入角色边界等协议标记；Tokenizer 再把结果映射成模型词表中的 Token ID。

如果协议格式与模型训练时看到的格式不匹配，即使文字内容相同，输入 Token 序列也会不同，模型表现可能明显下降。
