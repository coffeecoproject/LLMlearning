# 停止与文本恢复概览

> [!summary]
> 每轮选择 Token 后，生成控制器检查是否满足停止条件；结束后，配套 Tokenizer 把 Token ID 序列恢复成用户可读文本。

## 阅读顺序

1. [[01-生成循环怎样停止|生成循环怎样停止]]；
2. [[02-Token怎样恢复成文本|Token 怎样恢复成文本]]。

## 两个环节的边界

```text
停止条件：决定还要不要继续生成
Tokenizer Decode：把 Token ID 恢复为字节或文字
```

文本产生后怎样封装成网络事件并逐步发送，属于 [[00-接口流式传输与部署概览|Runtime 的接口与流式传输]]，不再放在单请求生成机制中。
