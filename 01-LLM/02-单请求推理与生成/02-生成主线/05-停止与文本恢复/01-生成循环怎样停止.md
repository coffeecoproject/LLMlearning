# 生成循环怎样停止

> [!summary]
> 自回归模型理论上可以一直续写，因此生成控制器必须在每一步检查 EOS、长度上限、自定义停止序列、上下文限制或取消请求等停止条件。

## 常见停止条件

| 条件 | 直白解释 |
|---|---|
| EOS Token | 模型选择了“序列结束”特殊 Token |
| `max_new_tokens` | 已生成的新 Token 达到上限 |
| 自定义 Stop | 生成了应用指定的 Token 或文本序列 |
| 上下文上限 | 输入与输出将超过可处理范围 |
| 客户端取消或超时 | 外部系统主动终止请求 |

## EOS 为什么不是普通句号

句号只是文本内容，后面仍可能继续下一句。EOS 是词表中的特殊控制 Token，表示模型认为序列可以结束。Tokenizer Decode 时它通常不会作为普通文字显示。

## 模型想停与系统强制停的区别

- 选择 EOS：模型分布参与决定；
- 达到 `max_new_tokens`：系统在外部强制终止；
- 用户取消：请求生命周期被外部事件终止。

因此，回答被截断不一定是模型“忘了继续”，也可能只是运行配置限制。

## Stop String 为什么更复杂

应用可能指定在出现某段文字时停止。但文字片段和 Token 边界未必一一对应，Runtime 可能需要对增量解码文本做匹配，并决定是否把停止文本保留在结果中。具体行为应以使用的 API 或生成库为准。

## 常见误解

- `max_new_tokens` 限制输出新增量，不一定等于总上下文长度。
- EOS Token ID 由配套 Tokenizer/模型配置决定，不是所有模型相同。
- 停止生成不会自动清除模型服务中的所有缓存；资源回收属于 Runtime 生命周期管理。
