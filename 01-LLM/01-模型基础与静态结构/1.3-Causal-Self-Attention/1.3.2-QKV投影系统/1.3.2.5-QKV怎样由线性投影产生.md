# 1.3.2.5 Q、K、V 怎样由线性投影产生

> [!summary]
> 模型使用三组学习得到的投影权重，把同一输入 Hidden State 映射成 Q、K、V；权重矩阵是长期参数，Q、K、V 是当前输入产生的临时结果。

## 什么叫线性投影

可以先把它理解为：

```text
输入一组数
→ 与一组学习得到的权重进行线性计算
→ 输出另一组数
```

同一个位置的 Hidden State `x` 分别经过三组投影：

```text
x → Q 投影 → q
x → K 投影 → k
x → V 投影 → v
```

可选数学写法是：

```text
q = xW_Q
k = xW_K
v = xW_V
```

其中 `W_Q`、`W_K`、`W_V` 是不同的模型参数矩阵。

## 为什么同一输入会得到不同结果

三组权重不同：

```text
W_Q ≠ W_K ≠ W_V
```

所以同一个 Hidden State 可以被重组为三种用途不同的表示。模型不是复制三份相同向量再改名字。

## 参数与运行结果要分开

| 对象 | 是什么 | 是否随当前输入变化 | 是否保存在模型权重中 |
|---|---|---:|---:|
| `W_Q`、`W_K`、`W_V` | 学习得到的投影参数 | 否 | 是 |
| Q、K、V | 当前 Hidden States 的投影结果 | 是 | 否 |

普通运行时读取固定投影参数，计算当前请求的 Q、K、V。训练怎样更新这些参数属于训练模块，不在这里展开。

## 从整条序列看形状

先使用单个 Attention Head 的教学模型。假设：

```text
sequence_length = 3
hidden_size = 4
head_dim = 2
```

输入 Hidden States：

```text
X：[3, 4]
```

若三种投影都从宽度 4 映射到宽度 2：

```text
W_Q：[4, 2] → Q：[3, 2]
W_K：[4, 2] → K：[3, 2]
W_V：[4, 2] → V：[3, 2]
```

含义是：三个位置各自得到一个二维 Q、K、V。

加入 Batch 后，可先理解为：

```text
X：[batch_size, sequence_length, hidden_size]
Q/K/V：[batch_size, sequence_length, head_dim]
```

## 为什么真实配置看起来更复杂

真实 LLM 通常同时计算多个 Head，工程实现还可能把多组投影合并在一个大矩阵中一次算出，再重新整理维度。

此外：

- MHA 中 Query Head 与 K/V Head 数量通常相同；
- GQA 中多个 Query Head 共享一组 K/V Head；
- MQA 中所有 Query Head 共享更少的 K/V Head。

因此真实 Q、K、V 张量形状不一定完全相同。当前示例只用于讲清单头投影；具体多头形状留到 `1.3.5` 和 `1.3.6`。

## 投影是否已经完成 Attention

没有。此时只是准备好三种角色向量：

```text
Hidden States
→ Q、K、V
```

接下来还需要：

```text
QK 点积
→ Scaling
→ Causal Mask
→ Softmax
→ Weight × V
```

## 常见误解

- **“Q、K、V 是三组模型参数。”** 投影矩阵是参数；Q、K、V 是参数作用于当前输入后的结果。
- **“三个投影只是把输入复制三次。”** 不同权重学习不同角色表示。
- **“真实模型中 Q、K、V 形状必然完全相同。”** GQA、MQA 等架构可能使用不同 Head 数量。
- **“产生 Q、K、V 后 Attention 就结束了。”** 它们只是后续匹配和汇总的准备。
