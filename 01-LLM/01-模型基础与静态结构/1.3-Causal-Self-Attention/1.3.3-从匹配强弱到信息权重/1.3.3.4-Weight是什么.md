# 1.3.3.4 Weight 是什么

> [!summary]
> Attention Weight 是把可见位置的 Scores 整理后得到的相对信息份额；它决定下一步从每个位置的 Value 中汇总多少内容。

## 从分数变成份额

教学示意：

```text
Score：  [1.2, -0.3, 2.1]
Weight： [0.27, 0.06, 0.67]
```

Weight 通常具有：

- 每项不小于 0；
- 同一个接收位置的一组 Weight 总和为 1；
- 被 Mask 的位置 Weight 为 0。

## Weight 用来做什么

下一步会使用：

```text
各位置 Weight × 对应 Value
→ 相加
→ 当前位置的上下文汇总
```

所以 Weight 不是最终答案，而是 Value 信息混合时的系数。

## Softmax 的必读直觉

Softmax 把一组高低不一、可正可负的 Scores 转换成相对份额：分数更高的位置通常获得更大 Weight，所有可见位置共同竞争总量 1。

当前不要求掌握指数函数。

## 可选技术补充：Softmax

Softmax 会先对每个 Score 取指数，再除以整组指数之和。程序还常先减去该行最大 Score 以提高数值稳定性。

对 Attention 矩阵而言，通常对每个 Query 对应的一行来源 Scores 分别做 Softmax，而不是把整张矩阵一起归一化。

## Weight 不是输出概率

```text
Attention Weight
→ 在来源位置之间分配 Value 汇总份额

输出 Token Probability
→ 在词表候选 Token 之间分配生成概率
```

二者都可能总和为 1，但分配对象完全不同。

## 常见误解

- **“Weight 是下一个 Token 的概率。”** 它分配的是来源位置的信息份额。
- **“最高 Weight 的位置是唯一信息来源。”** 多个 Value 通常共同参与加权和。
- **“Softmax 对整张 Attention 矩阵一起处理。”** 通常按每个 Query 的来源位置一行处理。
- **“Weight 完整解释了模型思考。”** 它只是某层某 Head 的局部系数。
