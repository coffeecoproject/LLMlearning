# 1.2.5 位置机制

> [!summary]
> Token Embedding 主要说明“是什么 Token”，位置机制补充“它在什么位置、与其他位置相隔多远”；不同方案把位置信息注入不同计算位置。

## 作用位置预览

```text
Absolute Position Embedding
→ 通常与输入 Token Embedding 结合

RoPE
→ 作用于 Attention 中的 Q 和 K

ALiBi
→ 向 Attention Score 加入与相对距离有关的偏置
```

## 边界

本节先建立“为什么需要”和“作用在哪里”。RoPE 数学推导、Q/K、Attention Score 的完整计算要等 [[模型基础与静态结构大纲#1.3 Causal Self-Attention|Causal Self-Attention]] 后才能真正讲透。

## 完成标准

学完后应能：

1. 解释为什么 Token 在张量中的排列顺序不会自动成为 Attention 可利用的位置关系；
2. 区分绝对位置与相对位置关系；
3. 指出 Absolute Position Embedding、RoPE 和 ALiBi 分别作用在哪里；
4. 避免用“给 Token 向量加一个位置向量”统一解释所有模型。
