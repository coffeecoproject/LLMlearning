# 1.2.4.4 表示在层与层之间怎样传递

> [!summary]
> 每个 Transformer Block 接收上一层整条序列的 Hidden States，更新每个位置的表示，再把相同基本形状的结果交给下一层。

## 先看完整路线

假设输入有 3 个 Token，`hidden_size = 4`：

```text
初始表示             [3, 4]
→ Transformer Block 1
第 1 层 Hidden States [3, 4]
→ Transformer Block 2
第 2 层 Hidden States [3, 4]
→ ……
最后一层 Hidden States [3, 4]
```

模型层数增加的是“连续处理次数”，不是必须不断增加张量维度。

## 为什么相邻层要保持相同宽度

如果模型的 `hidden_size = 4`，每一层对外都接收和输出宽度为 4 的位置表示，下一层就可以直接接过上一层结果。

真实模型的 `hidden_size` 通常远大于 4，但基本接口类似：

```text
上一层输出宽度
= 下一层输入宽度
= hidden_size
```

这使许多相同接口的 Transformer Block 可以顺序堆叠。

## 形状不变，什么在变化

以一个位置为例：

```text
第 0 层：[ 0.2,  0.5, -0.1, 0.7]
第 1 层：[ 0.4, -0.2,  0.8, 0.1]
第 2 层：[-0.3,  0.6,  0.2, 0.9]
```

这些数字是教学示意。它们说明：向量长度一直是 4，但数值不断改变，因此后续计算可以利用不同的特征与上下文关系。

```text
形状保持兼容
≠ 内容保持不变
```

## 一个 Block 大致做了什么

当前只建立结构预览：

```text
上一层 Hidden States
→ Attention：让不同可见位置交换、汇总信息
→ Residual Connection：把更新与已有表示结合
→ FFN / MLP：在每个位置内部进一步变换
→ Residual Connection：再次结合
→ 下一层 Hidden States
```

Normalization 还会参与稳定各子层的计算。不同模型可能采用 Pre-Norm、Post-Norm、RMSNorm 等不同安排。

这些组件将在 `1.3 Attention` 和 `1.4 Transformer Block` 中分别讲透；本篇只回答“表示如何作为层间数据继续传递”。

## “逐层理解得更深”这个比喻的边界

入门时可以把多层看成反复加工，但不能把每一层硬性命名为：

```text
第 1 层只识别字形
第 2 层只识别语法
第 3 层只识别知识
```

真实模型中的功能通常是分布式的，不同层可能表现出某些统计倾向，但没有一套对所有模型都成立的固定人类课程表。

## 最后一层之后发生什么

最后一层 Hidden States 仍然是内部向量。对于下一 Token 预测，模型会使用相关位置的最终表示，再经过 Final Normalization 和 LM Head，映射到词表大小的 Logits。

```text
最后一层 Hidden State
→ Final Norm
→ LM Head
→ vocab_size 个 Logits
```

这一步将在 `1.5 输出概率的形成` 中学习。

## 阶段边界

本篇描述的是模型结构中的前向数据流，训练和普通运行都会使用这套层间计算。区别是：

- 普通运行怎样组织完整生成循环，见 [[01-LLM/02-LLM普通运行与生成/LLM普通运行与生成大纲|LLM 普通运行与生成]]；
- 训练怎样根据误差更新每层参数，见 [[01-LLM/03-LLM训练与对齐/LLM训练与对齐大纲|LLM 训练与对齐]]。

这里不展开两条流程。

## 常见误解

- **“每经过一层，hidden_size 就会增加。”** Block 的外部表示宽度通常保持不变。
- **“形状相同说明各层输出相同。”** 形状相同只表示接口兼容，数值可以完全不同。
- **“每一层都有一个固定、可命名的人类认知任务。”** 功能通常分布在多层和多种参数中。
- **“Hidden State 传到下一层就是把文本复制一遍。”** 传递的是更新后的浮点向量张量。
