# 1.2.3 Embedding 参数的形成与使用

> [!summary]
> Embedding Matrix 不是人工编写的编码表，而是一组可学习参数：训练塑造其中的数值，训练完成后的普通运行只读取这些参数。

## 阶段边界

```text
【LLM 训练阶段】查表 → 前向计算 → 产生误差 → 更新 Embedding 参数
【LLM 运行阶段】查表 → 前向计算 → 输出；通常不更新参数
```

这里不展开反向传播公式，也不展开模型服务、请求调度、Batch 或 KV Cache。当前只解释 Embedding 参数怎样形成，以及训练结束后怎样参与模型计算。
