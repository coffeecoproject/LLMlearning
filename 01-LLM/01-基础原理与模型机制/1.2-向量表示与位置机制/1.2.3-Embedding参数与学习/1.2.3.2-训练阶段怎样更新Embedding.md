# 1.2.3.2 训练阶段怎样更新 Embedding

> [!summary]
> LLM 训练时先用 Token ID 查出 Embedding，经过整个模型产生预测，再根据预测误差反向计算每个相关参数应怎样调整；Embedding 因而与其他参数一起逐步学习。

## 先分清是哪一种训练

这里讨论的是 **LLM 参数训练**，不是 Tokenizer 训练：

```text
【Tokenizer 训练】
语料 → 学习词表和切分规则

【LLM 训练】
固定 Tokenizer → 文本变成 Token ID
→ 更新 Embedding、Attention、FFN 等神经网络参数
```

通常先确定 Tokenizer，再用稳定的 ID 映射训练 LLM。

## 一次训练更新的完整因果链

```text
1. 训练文本经过固定 Tokenizer
2. 得到 Token ID 序列
3. Embedding Lookup 取出相关参数行
4. 输入经过 Transformer 各层
5. 模型预测下一个 Token
6. 将预测与正确目标比较，得到 Loss
7. 反向传播计算参数调整方向
8. Optimizer 更新包括 Embedding 在内的参数
```

下面逐步理解为什么每一步必要。

## 1. 前向计算：先使用当前 Embedding

假设训练片段是：

```text
我 喜欢 苹果
```

模型用当前参数对各 Token 执行 Lookup，再经过后续网络预测目标。如果当前参数还不好，模型可能给错误 Token 很高分。

没有前向计算，就无法知道当前参数组合会产生怎样的预测。

## 2. Loss：把错误变成训练信号

Loss（损失）是衡量预测与训练目标差距的数值。可以先理解为：

```text
正确目标概率低 → Loss 较高
正确目标概率高 → Loss 较低
```

Loss 不会直接说“苹果向量第 37 维应该加多少”，它只是为整个预测结果提供一个可优化目标。

## 3. 反向传播：分配调整责任

反向传播（backpropagation）从 Loss 出发，沿计算路径反向计算：

> 每个参与此次预测的参数，如果稍微改变，会让 Loss 怎样变化？

这个变化方向和敏感程度通常用 Gradient（梯度）表示。

Embedding 是前向链路的一部分，因此被 Lookup 的相关行也可以收到梯度信号。没有反向传播，就无法把最终预测错误传回输入端的参数。

## 4. Optimizer：真正修改参数

Optimizer（优化器）读取梯度，并按照学习率等规则更新参数。极度简化地说：

```text
当前参数
→ 根据梯度做一次小调整
→ 得到更新后的参数
```

梯度负责提供方向信息，优化器负责执行更新；二者不是同一个概念。

## 为什么同类 Token 可能形成关系

假设“苹果”“香蕉”经常出现在相似上下文：

```text
我吃了一个苹果
我吃了一个香蕉
苹果是一种水果
香蕉是一种水果
```

它们对应的 Embedding 参数会反复参与相似的预测任务，并与模型其他参数一起被调整。久而久之，模型可能形成可复用的关系结构。

但必须保留边界：

- 不是每出现一次就把两个向量直接拉近；
- 优化目标是降低整个模型的预测 Loss；
- 相似关系是整体训练结果，不是人工规定的单条规则；
- 最终语义还分布在 Transformer 的其他参数与 Hidden State 中。

## 是否只更新当前出现的 Embedding 行

在标准 Lookup 的直接输入路径上，本批次出现的 Token 行会参与计算并接收相应梯度；没有被查到的行通常不会从这条输入路径收到直接梯度。

但某个模型还可能在输出侧使用或共享词表权重，这会引入额外更新路径。因此不能脱离具体架构笼统断言“一次训练只影响出现过的几行”。

当前只需理解：

> 被 Lookup 的 Embedding 行不是孤立学习，而是通过整个预测任务收到训练信号。

## Batch 在训练中起什么作用

一个 Batch 中可能有多条训练序列。模型计算这些样本的 Loss，并综合产生一次参数更新所需的梯度信号。

```text
多条样本
→ 一次批量前向计算
→ 汇总 Loss / 梯度
→ 一次优化器更新
```

这里的 Batch 不改变 Embedding 的基本机制：每条序列仍先按自己的 Token ID 查表。

## 常见误解

- **“Tokenizer 训练会直接学出 LLM 的 Embedding。”** Tokenizer 只确定词表和 ID；Embedding 在 LLM 训练中学习。
- **“Loss 会直接告诉模型正确答案的向量。”** Loss 提供优化目标，梯度和优化器共同完成参数调整。
- **“相似上下文会把向量简单复制成一样。”** 模型优化的是整体预测，不是执行固定的向量复制规则。
- **“一次更新后 Embedding 就学会了词义。”** 有用表示来自大量样本和长期联合训练。
