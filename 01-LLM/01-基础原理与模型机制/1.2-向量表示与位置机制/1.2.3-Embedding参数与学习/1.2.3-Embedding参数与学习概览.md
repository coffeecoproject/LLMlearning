# 1.2.3 Embedding 参数与学习

> [!summary]
> Embedding Matrix 不是人工编写的语义字典，而是 LLM 的一组可学习参数：训练时根据误差更新，普通运行时只读取。

## 子结构

1. [[1.2.3.1-Embedding是参数不是固定编码表|Embedding 是参数，不是固定编码表]] ✓
2. [[1.2.3.2-训练阶段怎样更新Embedding|训练阶段怎样更新 Embedding]] ✓
3. [[1.2.3.3-运行阶段只查表不学习|运行阶段只查表、不学习]] ✓
4. [[1.2.3.4-Embedding-Space与语义边界|Embedding Space 与语义边界]] ✓

## 阶段边界

```text
【LLM 训练阶段】查表 → 前向计算 → 产生误差 → 更新 Embedding 参数
【LLM 运行阶段】查表 → 前向计算 → 输出；通常不更新参数
```

这里不展开反向传播公式，只解释为什么训练可以逐渐塑造向量关系。
