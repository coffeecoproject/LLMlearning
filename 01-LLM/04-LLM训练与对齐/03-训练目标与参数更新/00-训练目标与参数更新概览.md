# 训练目标与参数更新概览

> [!summary]
> 模型先用当前参数预测下一 Token，Loss 衡量预测偏差，Backward 计算 Gradient，Optimizer 才真正修改参数。

## 一次更新的主线

```text
训练 Batch
→ Forward
→ Logits
→ Loss
→ Backward
→ Gradient
→ Optimizer Step
→ 新参数
```

普通运行在 Logits 后选择 Token，不会继续执行 Loss、Backward 和 Optimizer Step。

## 一个直白例子

```text
上下文：我 喜欢
真实目标：苹果

当前预测：
香蕉 60%
苹果 20%
汽车 20%
```

正确 Token“苹果”的概率较低，因此产生较高 Loss。Backward 把这个误差信号追溯到相关参数，Optimizer 再进行一次小幅更新。

## 四个对象不要混淆

| 对象 | 作用 | 是否修改参数 |
|---|---|---:|
| Forward | 用当前参数得到预测 | 否 |
| Loss | 把预测偏差表示成数值 | 否 |
| Backward | 计算参数的 Gradient | 否 |
| Optimizer Step | 根据 Gradient 更新参数 | 是 |

## 训练与运行的分叉

```text
共同：Token → Transformer → Logits

训练：Logits + Labels → Loss → Backward → 参数改变
运行：Logits → Token 选择 → 参数保持不变
```

## 数学尺度

主线只需知道：正确 Token 概率越低，Cross-Entropy Loss 通常越高。对数、梯度推导和优化器公式全部属于选读。
