## 复习目标

学完后应能不依赖公式重新讲出：

```text
训练 Batch
→ Forward 使用当前参数
→ Logits 表达当前预测
→ Labels 提供正确目标
→ Loss 衡量偏差
→ Backward 计算 Gradient
→ Optimizer 更新参数
→ Step 增加
→ 必要时保存 Checkpoint
```
