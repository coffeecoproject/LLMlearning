# 一次参数更新怎样完整发生

> [!summary] 一句话理解
> 训练文本先提供下一 Token 的正确目标，模型用当前参数预测；Loss 衡量偏差，Backward 计算 Gradient，Optimizer 最后修改参数。

## 所属阶段

**训练阶段。** 这篇只负责把已经学过的概念串成一条主线，不展开工程实现。

## 示例准备

使用一条简化句子：

```text
我 喜欢 苹果 <EOS>
```

假设它恰好被分成以上四个 Token。真实切分由具体 Tokenizer 决定。

## 第一步：构造输入与目标

Causal Language Modeling 根据左侧内容预测下一个 Token：

| 当前可见内容 | 正确目标 |
|---|---|
| `我` | `喜欢` |
| `我 喜欢` | `苹果` |
| `我 喜欢 苹果` | `<EOS>` |

```text
Input： 我    喜欢   苹果
Label： 喜欢  苹果   <EOS>
```

训练程序虽然持有完整句子，Causal Mask 仍保证每个位置不能直接读取未来 Token。

## 第二步：Forward 产生预测

```text
Token IDs
→ Embedding 与位置信息
→ Transformer Blocks
→ Hidden States
→ 输出层
→ Logits
```

假设在预测“苹果”的位置，模型得到以下**虚构教学概率**：

| 候选 Token | 概率 |
|---|---:|
| `苹果` | 20% |
| `香蕉` | 54% |
| `汽车` | 26% |

当前模型更倾向“香蕉”，而正确 Label 是“苹果”。

## 第三步：Loss 表示偏差

正确 Token 只有 20% 概率，因此这个位置产生较高 Loss。其他有效位置也会产生各自的 Token Loss，训练程序再把它们汇总成当前 Batch Loss。

```text
各位置的预测与 Label
→ 各位置 Token Loss
→ 当前 Batch Loss
```

Batch Loss 只是对全部训练目标的一次局部观察。

## 第四步：Backward 计算 Gradient

Backward 从 Loss 沿 Forward 的计算关系向前追溯：

```text
Loss
→ 输出层
→ Transformer Blocks
→ Attention、FFN、Embedding 等参数
```

结果不是一段文字解释，而是大量参数各自的 Gradient：如果某个参数轻微变化，Loss 大致会朝哪个方向变化。

不能把其中一个参数简单命名为“苹果参数”，因为预测来自许多层和参数的共同作用。

## 第五步：Optimizer 修改参数

用一个参数做纯教学示意：

```text
旧参数：1.00
Gradient：+0.40
Learning Rate：0.10
新参数：1.00 - 0.10 × 0.40 = 0.96
```

真实 Optimizer 会同时更新大量参数，并使用更完整的规则。到这一步，模型参数才第一次真正改变。

## 第六步：用新参数继续训练

下一次 Forward 会读取更新后的参数，因此 Hidden States、Logits 和概率分布都可能略有变化。

但一次更新不会让模型突然掌握“苹果”知识，也不保证这个单独样本立刻预测正确。模型能力来自大量不同 Batch 与大量 Step 的累积。

## 完整主线

```text
训练文本
→ Tokenizer 得到 Token IDs
→ 构造下一 Token Labels
→ Forward 得到 Logits
→ Loss 衡量预测偏差
→ Backward 得到 Gradients
→ Optimizer Step 修改参数
→ 用新参数处理下一批数据
```

普通运行会在 Logits 后选择 Token 并继续生成，不会执行 Labels、Loss、Backward 和 Optimizer Step。

## 这一步改变与不改变什么

| 对象 | 是否被一次 Optimizer Step 改变 |
|---|---:|
| 模型参数 | 是 |
| Tokenizer 词表与切分规则 | 通常否 |
| 模型层数、Hidden Size | 通常否 |
| 原始训练文本 | 否 |
| 用户当前对话 Session | 无直接关系 |

## 常见误解

### 预训练要先生成完整错误答案，再由人纠正

通常不是。完整训练文本已经提供 Labels，程序直接比较各位置的概率分布与正确 Token。

### 一条序列只训练最后一个 Token

通常不是。序列中的多个有效位置可以同时提供下一 Token 目标。

### 一次更新把一句知识存进一个固定参数

不是。一次更新是许多参数的微小协同变化。
