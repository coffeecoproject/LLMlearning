# 训练进度与状态概览

> [!summary]
> Batch 描述一次处理哪些样本，Step 描述参数更新次数，Epoch 描述数据轮次，Token Budget 描述总训练规模，Checkpoint 保存训练状态。

## 两个选读问题

1. [[01-Batch-Step-Epoch与Token-Budget怎样区分|Batch、Step、Epoch 与 Token Budget 怎样区分]]
2. [[03-Checkpoint保存什么|Checkpoint 保存什么]]

## 先记住的关系

```text
一个 Batch
→ Forward 与 Backward
→ 一次 Optimizer Step
→ 参数更新

若遍历完定义的数据集合
→ 可以称为完成一个 Epoch

大模型预训练规模
→ 常额外用总 Token 数和 Step 数描述
```

这些概念描述训练组织方式，不是新的模型层。
