# Causal Language Modeling 与下一 Token 目标

> [!summary]
> Causal Language Modeling 让模型根据当前位置左侧已经出现的 Token 预测下一个 Token；大量位置上的这种小任务共同构成 Decoder-only LLM 的常见预训练目标。

## 为什么选择“预测下一 Token”

大量原始文本并没有人工标注：

```text
这句话训练什么能力？
正确类别是什么？
应该输出什么标签？
```

但文本本身已经天然提供顺序：

```text
我 | 喜欢 | 苹果
```

因此可以自动构造：

```text
看到“我”          → 目标是“喜欢”
看到“我 喜欢”     → 目标是“苹果”
```

不需要人给每句话单独写标签，就能从大规模文本产生大量训练位置。

## Causal 是什么意思

这里的 Causal 可以先理解为“按因果时间方向读取”：

```text
当前位置
→ 可以利用左边和当前位置的信息
→ 不能利用右边尚未发生的信息
```

例如：

```text
小明把苹果给了小红，因为她喜欢水果。
```

模型预测“喜欢”前面的 Token 时，不能把后面完整句子提前作为输入。这个限制由 Causal Mask 保证。

> [!important] 名称边界
> 这里的 `Causal` 描述 Token 信息的读取方向，不表示模型仅凭这个训练目标就掌握了现实世界中的因果关系。模型仍可能只学到相关性，也可能对真实因果关系作出错误判断。

## 一条序列能提供多少训练位置

> [!example] 教学示意
> 假设每个词恰好是一个 Token。

```text
序列：我 | 喜欢 | 苹果 | EOS
```

可以形成：

| 模型在该位置拥有的上下文 | 下一 Token 目标 |
|---|---|
| 我 | 喜欢 |
| 我 喜欢 | 苹果 |
| 我 喜欢 苹果 | EOS |

所以长度为 4 的序列，不是只产生一个训练判断，而是可以在多个有效位置计算预测误差。

## 为什么训练可以同时计算多个位置

训练阶段已经拥有完整序列，计算设备可以一次建立全部位置的表示：

```text
位置1预测位置2
位置2预测位置3
位置3预测位置4
```

Causal Mask 确保每个位置只能读取允许的信息，因此这些位置可以并行计算，而没有互相偷看未来。

这与普通生成不同：

```text
训练：正确后续已经存在，可同时计算多个位置的 Loss
运行：未来 Token 尚不存在，必须先选出一个，再进入下一轮 Decode
```

## 它怎样产生更复杂的能力

表面目标只是预测 Token，但为了在大量文本上持续做好预测，模型需要逐渐形成对以下关系的可用表示：

- 语法和词语搭配；
- 指代和上下文关系；
- 事实共现与知识结构；
- 代码语法和程序模式；
- 数学与推理文本中的步骤结构；
- 不同任务和回答形式。

这不表示模型被显式要求“建立世界模型”，而是这些内部结构有助于降低广泛数据上的预测 Loss。

## Next Token Prediction 不等于查找答案

训练没有建立：

```text
问题 → 固定数据库答案
```

它更新的是分散在模型参数中的统计关系。运行时模型再根据当前上下文重新计算下一 Token 分布。

因此它可能：

- 生成训练数据中未出现过的组合；
- 对相似问题进行一定泛化；
- 也可能产生听起来合理但事实错误的内容。

## 它是所有模型唯一的训练目标吗

不是。

Decoder-only LLM 常以 Causal LM 为基础，但现代模型还可能加入：

- Multi-Token Prediction；
- 多模态目标；
- 指令微调目标；
- 偏好优化；
- 强化学习奖励；
- 工具调用和 Agent 轨迹训练。

这些属于后续预训练变体或后训练内容，不改变本篇基础主线。

## 常见误解

- **“预测下一个 Token 只能学会接龙。”** 接龙是表面任务，做好大规模预测需要形成大量可复用关系。
- **“训练时有完整文本，所以模型可以直接复制未来。”** Causal Mask 阻止当前位置读取未来表示。
- **“一次 Forward 同时预测多个位置，等于运行时一次生成多个 Token。”** 训练有真实目标；运行时未来输出尚不存在。
- **“Next Token Prediction 可以保证事实正确。”** 它优化训练分布上的预测，不提供独立事实验证。

## 理解检查

1. 为什么原始文本天然可以提供下一 Token 标签？
2. 训练为什么能并行计算多个位置，却没有违反 Causal Mask？
3. Next Token Prediction 为什么可能产生推理能力，也仍可能产生幻觉？
