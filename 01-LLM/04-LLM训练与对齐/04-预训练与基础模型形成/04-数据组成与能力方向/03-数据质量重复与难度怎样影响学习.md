# 数据质量、重复与难度怎样影响学习

> [!summary] 一句话理解
> 相同数量的 Token 可以提供完全不同的训练价值：清晰、多样且难度合适的数据更可能推动可复用规律，错误和过度重复的数据则可能制造噪声、记忆与预算浪费。

## 为什么 Token 数量不够说明数据价值

比较两段代码：

```text
数据 A：可运行实现 + 清晰注释 + 对应测试
数据 B：截断代码 + 错误变量 + 大量复制模板
```

两者可能拥有相同 Token 数，却提供不同训练信号。模型不会自动知道 A 更可靠；进入 Loss 的目标 Token 都会影响参数。

## 数据质量影响什么

高质量不是单一标签，它可能包括：

- 内容正确或至少内部一致；
- 表达清楚，结构完整；
- 信息密度较高；
- 覆盖目标领域与任务；
- 不被模板、广告和乱码主导；
- 与其他数据共同形成合理分布。

质量规则也可能误删少数语言、非标准表达或有价值的困难样本，因此“过滤更多”不一定始终更好。

## 重复为什么既能加强又会伤害

同一模式多次出现，会增加训练权重。适度重复可能帮助模型稳定学习重要结构，但过度重复会带来：

- 有限计算预算反复花在相同内容上；
- 罕见重复文本被异常放大；
- 更容易逐字记忆训练片段；
- 数据多样性下降；
- 评估集若与训练集重复，会产生虚高成绩。

因此重复不是简单的“出现两次就有害”，而是要看重复程度、内容价值和整体预算。

原始研究曾发现，训练语料去重可以减少模型逐字复现训练文本，并改善训练效率和评估可靠性。

来源：[Deduplicating Training Data Makes Language Models Better](https://arxiv.org/abs/2107.06499)，核对日期：2026-07-28。

## 数据难度为什么重要

### 过于简单

如果模型已经能轻易预测大量模板文本，这些 Token 仍会消耗计算，但提供的新信息可能有限。

### 过于混乱

如果输入缺少必要上下文、答案错误或推导断裂，模型得到的可能是矛盾信号，而不是更高难度的有效学习。

### 难度合适且结构清楚

有明确条件、完整过程和可验证结果的数据，更有机会推动模型学习复杂关系。

“困难”不等于“高质量”，简单基础文本也可能非常重要；关键是训练阶段、模型当前能力和目标是否匹配。

## 合成数据的双重作用

Synthetic Data（合成数据）由模型、程序或规则生成，可以：

- 扩展稀缺任务；
- 控制格式和难度；
- 生成可验证代码、数学或工具样本；
- 补充特定语言和领域。

但如果生成器本身错误、风格单一或缺乏真实分布，合成数据也可能放大偏差和错误。通常仍需要过滤、验证和与真实数据合理混合。

## 质量与多样性的关系

极度追求统一“标准答案”，可能让数据风格变窄；只追求多样，又可能引入大量噪声。

真实数据设计需要平衡：

```text
正确性与完整性
+ 表达和领域多样性
+ 合理难度
+ 有限重复
→ 更有效的训练信号
```

## 常见误解

### 高质量数据一定是语言最正式的数据

不是。质量取决于目标；真实对话、口语和代码日志也可能很有价值。

### 重复数据一定毫无价值

不是。适度重复会改变学习权重，问题在于过度重复和预算失衡。

### 合成数据天然比真实数据差

不一定。关键是生成方法、验证强度、覆盖范围和混合方式。
