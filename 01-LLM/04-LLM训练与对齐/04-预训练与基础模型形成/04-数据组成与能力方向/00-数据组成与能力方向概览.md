# 数据组成与能力方向概览

> [!summary]
> 训练数据决定模型反复获得哪些预测目标，因此会影响语言、知识、代码、数学和领域能力的发展方向；但数据比例与能力强弱不是简单的线性换算。

## 这部分处于哪里

```text
训练数据的内容与比例
→ 不同模式获得不同数量的训练信号
→ 参数在有限容量和计算预算中形成不同倾向
→ Base Model 呈现不同能力方向
```

本小节不重复“数据怎样装入训练管线”，而是继续回答“这些选择为什么会长期改变能力”。

## 一个贯穿例子

假设两种模型架构和参数规模相近，但训练数据不同：

```text
模型 A：通用网页、书籍和百科占比较高
模型 B：在通用数据之外，提高了代码和软件文档的训练机会
```

模型 B 可能形成更强的代码补全与程序结构能力，但不能仅据此保证：

- 所有编程语言都更强；
- 代码正确率按数据比例提升；
- 通用语言能力完全不受影响；
- 模型能自动使用真实开发工具。

数据组成改变的是学习机会和优化压力，不是给模型安装一个确定的软件功能。

## “能力方向”是什么意思

能力方向不是一个单独参数，而是模型在不同任务分布上的相对表现倾向，例如：

- 哪些语言覆盖更好；
- 哪些领域概念更丰富；
- 代码、数学或长文本模式是否获得充分训练；
- 哪些文本风格与格式更熟悉；
- 面对新样本时，哪些规律更容易被调用。

这些方向最终需要独立评估验证，不能只从训练配方宣称。

## 本节的边界

- 不重复数据抓取、许可、过滤和去重的工程步骤；
- 不把某类文件数量等同于最终训练采样比例；
- 不把数据相关性说成唯一因果来源；
- 不根据一个公开数据数字反推闭源模型完整训练集；
- 不在这里展开参数规模、MoE 或 Scaling Law，它们属于下一小节。

## 学完后的判断标准

你应该能够解释：

1. 为什么代码、数学和多语言数据提供的训练机会不同；
2. 为什么提高某类数据比例可能同时产生迁移、干扰和收益递减；
3. 为什么重复数据既可能加强记忆，也可能浪费训练预算；
4. 为什么“20% 代码数据”绝不等于“20% 代码能力”。
