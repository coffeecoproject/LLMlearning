# 不同类型数据分别提供什么学习机会

> [!summary] 一句话理解
> 每类训练数据都通过自己的 Token、结构和上下文关系提供预测目标；模型反复看到哪些模式，就更有机会形成处理这些模式的参数倾向。

## 所属阶段

**预训练阶段。** 这里讨论最终进入训练 Batch 的有效数据，不讨论原始文件怎样抓取和清洗。

## 自然语言文本提供什么

书籍、网页、百科、新闻和论坛等文本可能提供：

- 词义、语法和篇章结构；
- 人物、地点、事件和概念关系；
- 不同语气、体裁和表达方式；
- 问答、论述、叙事和对话模式。

但“自然语言”不是一个同质类别。百科与论坛、正式论文与广告模板提供的训练信号差异很大。

## 多语言数据提供什么

中文、英文、西班牙语等语言具有不同 Token 分布、语法和文化知识。

```text
某种语言获得更多且更丰富的训练上下文
→ 相关词义、结构和知识获得更多更新机会
→ 该语言能力可能更稳定
```

多语言还可能产生迁移：不同语言共享概念、代码符号、数字和部分语义关系。但资源较少的语言也可能被高资源语言压制。

## 代码数据提供什么

代码除了普通 Token 共现，还包含非常强的结构约束：

- 语法必须匹配；
- 变量和函数存在依赖关系；
- 括号、缩进和类型需要保持一致；
- 文档、测试和实现之间存在对应关系。

这些数据能提供代码补全、程序结构和部分问题分解的学习机会。但训练代码不等于真正执行代码，模型仍可能生成语法正确但逻辑错误的程序。

## 数学与推导数据提供什么

数学表达、证明、题解和可验证答案可能提供：

- 符号规则与公式结构；
- 多步变换的文本模式；
- 问题、过程与答案之间的关系；
- 某些可以程序化检查的结果。

只有最终答案、包含完整过程的题解、错误过程和高质量证明，提供的训练信号并不相同。

## 领域数据提供什么

医学、法律、金融、科学等专业文本可以增加：

- 领域术语和表达；
- 专业实体及其关系；
- 常见文档结构和工作语境；
- 领域任务的表面与深层模式。

但领域文本多，不自动等于模型能够承担专业责任。真实应用仍需要最新数据、工具、验证和权限边界。

## 数据之间不是完全隔离的

一份软件文档可能同时包含：

```text
自然语言说明
+ 代码示例
+ 表格
+ 数学复杂度
+ 命令行格式
```

因此不能把每个 Token 精确归入一个单一能力盒子。不同类型数据可以互相促进，也可能争夺有限训练预算。

## 为什么“看过”不等于“掌握”

某项内容进入训练集，只表示它有机会产生 Gradient。最终能否形成稳定能力还取决于：

- 出现次数与表达多样性；
- 内容是否正确、清晰并适合学习；
- 模型容量和训练计算是否足够；
- 是否被其他冲突数据抵消；
- 评估问题是否与训练分布相近。

所以数据提供的是训练机会，不是能力保证书。

## 常见误解

### 代码数据只会影响代码能力

不一定。代码中的结构、文档和问题分解模式可能迁移到其他任务，反过来也可能与自然语言能力共享参数。

### 某个领域文件很多，模型就一定专业可靠

不是。数量、质量、覆盖、更新时效和实际验证都很重要。

### 训练数据类别之间界限非常清晰

不是。真实文档经常同时包含多种结构和能力信号。
