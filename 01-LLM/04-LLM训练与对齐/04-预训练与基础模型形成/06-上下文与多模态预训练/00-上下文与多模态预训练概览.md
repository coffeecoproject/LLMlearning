# 上下文与多模态预训练概览

> [!summary]
> 长上下文和多模态能力都需要匹配的数据、表示连接与训练目标；只扩大配置中的长度或增加一个输入接口，并不会自动形成可靠能力。

## 五个学习问题

1. [[01-上下文窗口长度与长上下文能力为什么不是一回事|上下文窗口长度与长上下文能力为什么不是一回事]]：区分结构允许、训练见过、实际能够利用；
2. [[02-长上下文能力怎样通过训练形成|长上下文能力怎样通过训练形成]]：理解位置机制、长序列数据和分阶段训练怎样配合；
3. [[03-图像音频和视频怎样变成模型可处理的表示|图像、音频和视频怎样变成模型可处理的表示]]：理解 Encoder、表示序列与连接层；
4. [[04-多模态能力怎样通过数据和训练形成|多模态能力怎样通过数据和训练形成]]：区分表示对齐、联合预训练与指令对齐；
5. [[05-原生多模态模型与外部工具有什么不同|原生多模态模型与外部工具有什么不同]]：区分模型内部能力、组合模型管线和 Agent 调用工具。

## 一条主线

```text
更长的位置与计算结构
+ 真正的长序列训练样本
+ 能迫使模型利用远距离信息的训练信号
→ 长上下文能力

图像、音频或视频
→ 专用编码或离散化
→ 模型能够接收的向量 / Token 序列
+ 跨模态配对数据与训练目标
→ 多模态能力
```

两条路线的共同点是：**接口能够容纳某类输入，只代表信息可以进入计算图；是否能正确利用，仍取决于训练和评估。**

## 边界

这里讲能力怎样训练形成，不重复以下内容：

- 上下文窗口在一次请求中怎样计算，见 [[00-上下文与多轮交互概览|上下文与多轮交互]]；
- RoPE、Absolute Position 和 ALiBi 的结构，见 [[00-Position位置机制概览|Position 位置机制]]；
- 长序列带来的显存、并行和 Kernel 问题，属于 [[00-规模化训练系统概览|规模化训练系统]]；
- 不展开 Vision Transformer、音频 Codec 或视频采样的实现公式；
- 多模态模型能够读取图片，不等于它能读取用户硬盘或主动操作软件；后者属于 Agent 与工具权限；
- OpenAI 闭源模型没有公开的编码器、Token 数和训练阶段，不从产品表现反推。
