# 许多样本与 Step 怎样共同改变参数

> [!summary] 一句话理解
> 每个 Batch 只给参数一次局部修正；相似规律在许多不同样本中反复出现时，相关更新倾向会长期累积，而冲突、噪声和其他任务也会共同影响最终参数。

## 所属阶段

**预训练阶段。** 本篇解释从“一次更新”到“长期能力”的时间尺度变化。

## 单次更新为什么很有限

假设某个教学参数当前是：

```text
0.500
```

一个 Batch 经过 Loss、Backward 和 Optimizer 后，使它变成：

```text
0.498
```

下一批数据可能又把它变成：

```text
0.501
```

这些数字完全是教学示意。它说明：不同 Batch 可能提出不同甚至相反的局部要求，单次变化不能独自决定参数最后“表示什么”。

## 相似规律为什么能够累积

假设训练数据反复出现：

```text
猫在追老鼠。
小猫追着玩具跑。
The cat chased the mouse.
老鼠被猫追赶。
```

句子表面不同，但共享若干关系：角色、动作、语法结构、动物概念和上下文搭配。

如果某种参数调整能帮助其中许多样本降低 Loss，它就可能在后续训练中不断得到支持。反之，只对极少数样本有利、却损害大量其他样本的调整，可能被后续更新抵消。

因此长期训练更像：

```text
大量局部要求不断叠加、竞争和折中
→ 参数寻找对许多样本都较有用的配置
```

它不是给每条文本分配一格独立存储空间。

## 数据频率、质量和多样性怎样参与

- **频率**：某种模式出现越多，通常获得的训练机会越多；
- **质量**：错误、冲突和噪声也会产生 Gradient，不会自动失效；
- **多样性**：同一关系出现在不同表达中，更有机会推动可复用规律，而不只是固定表面形式；
- **数据混合**：语言、代码、数学和领域数据的比例，会改变不同训练信号出现的机会。

所以“多喂数据”不是完整答案。数据必须与模型容量、训练目标和计算预算一起看。

## 规模不是单一数字

至少要区分：

| 维度 | 直白含义 |
|---|---|
| Training Tokens | 模型在训练中处理了多少 Token |
| Parameters | 模型有多少可调整的数值容量 |
| Training Steps | Optimizer 执行了多少轮有效更新 |
| Compute | 完成这些计算投入了多少计算资源 |
| Data Distribution | 这些 Token 实际包含什么内容和比例 |

参数多但训练 Token 不足，模型可能没有得到足够信号；数据很多但模型或计算不足，也可能无法充分吸收。如何分配这些量属于 Scaling Law 的选读内容。

## 一个真实规模观察：Qwen2.5

Qwen2.5 技术报告公开说明，其预训练数据规模从上一代约 7 万亿 Token 扩展到约 18 万亿 Token。

这个数字说明真实预训练与“反复读几篇文章”不是同一量级。但它不能单独告诉我们：

- 每个 Token 是否唯一；
- 每类数据占比是多少；
- 某项能力来自哪一个具体样本；
- 只扩大 Token 数是否必然得到同样提升。

来源：[Qwen2.5 Technical Report](https://arxiv.org/abs/2412.15115)，核对日期：2026-07-28。

## 为什么训练 Loss 通常呈总体趋势

每个 Batch 的内容不同，局部 Loss 可以上下波动。训练关心的是较长范围内的总体趋势：参数是否逐渐更能预测目标数据分布。

```text
单个 Batch：可能高、可能低
较长训练区间：观察平均趋势
最终能力：还要用独立评估验证
```

因此不能拿一个 Batch Loss 的下降，直接证明模型已经获得稳定能力。

## 选读：Scaling Law 提供什么证据

Scaling Law 研究观察模型规模、数据量、计算量与验证 Loss 之间的经验关系。Kaplan 等人的研究发现 Loss 会随这些规模量呈现较稳定的经验趋势；Chinchilla 研究进一步强调，在固定计算预算下，参数量和训练 Token 数需要合理配比。

这些是经验规律，不是“参数翻倍，所有能力必然翻倍”的保证。

来源：[Scaling Laws for Neural Language Models](https://arxiv.org/abs/2001.08361)、[Training Compute-Optimal Large Language Models](https://arxiv.org/abs/2203.15556)，核对日期：2026-07-28。

## 常见误解

### 同一句话出现十次，模型就精确记住十倍

不能这样线性理解。更新会与其他样本、优化器状态和已有参数共同作用。

### 参数越多，能力就自动越强

不一定。还需要足够、合适的数据和训练计算。

### 训练 Token 越多，任何能力都必然提升

不一定。数据组成、质量、模型容量和目标都会限制结果。

2. “训练规模”至少包含哪些不同维度？
3. 为什么 18 万亿 Token 不能直接解释某项具体能力来自哪里？
