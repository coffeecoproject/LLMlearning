# 内部表示为什么能够形成与复用

> [!summary] 一句话理解
> 训练逐渐改变参数，使 Transformer 能把当前 Token 与上下文转换成有用的 Hidden State；这些上下文相关的表示可以在许多不同任务中被重复利用。

## 所属阶段

**预训练阶段形成参数，运行阶段使用参数。** 本篇需要同时区分两阶段，但不会把它们混在一起。

## 先区分参数与表示

### 参数

参数是训练长期保留下来的数值，例如 Embedding、Attention、FFN 和输出层的权重。普通运行时主要读取它们。

### Hidden State

Hidden State 是模型处理当前这段 Token 时临时产生的上下文表示。输入或位置改变，Hidden State 也会改变。

```text
训练：改变参数，使计算规则逐渐有用
运行：使用已经学好的参数，为当前输入生成 Hidden State
```

因此，参数更像长期形成的计算倾向；Hidden State 是这些倾向在当前上下文中的具体结果。

## 一个词为什么需要不同表示

看“苹果”在两个句子中的含义：

```text
我刚吃了一个苹果。
苹果发布了新款电脑。
```

同一个文字在第一句更可能指水果，在第二句更可能指公司。单独的 Token Embedding 只是起点；经过 Attention 和多层 Transformer 后，当前位置的 Hidden State 会混入周围上下文，从而形成不同表示。

模型要预测合适后续，就必须区分这些语境。长期训练会不断奖励有助于区分语境的参数变化。

## 各组件怎样参与

```text
Token Embedding
→ 提供 Token 的初始向量
→ Attention 混合相关上下文
→ FFN 对当前位置表示进行非线性变换
→ 多层 Block 反复加工
→ 得到当前上下文中的 Hidden State
→ 输出层映射到下一个 Token 倾向
```

- Embedding 逐渐形成有用的初始关系；
- Attention 学会在不同上下文中读取不同位置；
- FFN 对已经混合的表示进行更丰富的特征变换；
- 多层堆叠让简单关系可以逐步组合成更复杂的上下文表示。

这里不是说每一层只有一个固定职责。真实功能通常由多个组件协同完成。

## 为什么表示能够复用

假设模型在大量文本中学到日期、地点、人物、因果词和代码结构的相关模式。这些模式并不只服务于一条句子。

面对新输入时，它们可以重新参与组合：

```text
已经形成的语言结构
+ 当前 Prompt 中的人物与约束
+ 当前上下文中检索到的关系
→ 当前问题的 Hidden States
→ 新的输出序列
```

这使模型有可能处理训练数据中没有原样出现的表达。

## 知识到底存在哪里

最稳妥的说法是：

> 模型的行为倾向由许多参数和运行时表示共同产生，通常不能把一项知识等同于某一个可直接读取的参数。

一些研究能够定位或编辑与特定事实相关的层或权重，但这不证明每个事实都有唯一、稳定、彼此独立的存储地址。不同事实、表达和计算路径可能共享参数，定位结果也取决于方法和模型。

因此学习阶段应避免两种极端：

- “知识完全找不到任何相关结构”；
- “每项知识都像数据库一样住在固定单元格”。

研究示例：[Locating and Editing Factual Associations in GPT](https://arxiv.org/abs/2202.05262)。这类研究提供局部证据，不构成完整的模型知识地图。

## 为什么会出现干扰和不稳定调用

由于许多模式共享参数：

- 新训练可能同时改变多项已有行为；
- 相互冲突的数据可能形成折中概率；
- 同一知识在不同 Prompt 下未必都能稳定调用；
- 模型知道某种关系，不代表每次生成都会选中正确 Token。

这也是参数化知识与数据库精确检索的重要区别。

## 常见误解

### Embedding 就是模型对一个词的完整理解

不是。Embedding 只是初始表示，真正用于当前预测的是多层处理后的上下文 Hidden State。

### Hidden State 会永久写回模型参数

普通运行不会。Hidden State 通常只服务于当前计算；只有训练闭环才会通过 Gradient 更新参数。

### 找到一个与事实相关的层，就找到了事实的唯一地址

不能这样下结论。相关、可编辑和唯一存储不是同一概念。
