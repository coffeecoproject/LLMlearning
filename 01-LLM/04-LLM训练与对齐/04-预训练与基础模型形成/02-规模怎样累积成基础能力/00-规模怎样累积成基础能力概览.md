# 规模怎样累积成基础能力概览

> [!summary]
> 下一 Token 预测提供的是局部训练信号；当模型在大量不同上下文中反复降低 Loss 时，许多参数会逐渐形成能够复用的语言规律、上下文表示和知识倾向。

## 这部分要解决的核心疑问

一次参数更新只是很小的数值变化，为什么重复很多次后，模型却能续写、回答问题、写代码，甚至处理没有原样见过的组合？

中间的因果链是：

```text
许多不同文本提供下一 Token 目标
→ 相似规律反复产生相关训练信号
→ 参数逐步保留有助于多类样本的变化
→ Hidden State 能表达更丰富的上下文
→ 已学模式可在新输入中被重新组合
→ 形成基础能力
```

这里的“形成”是长期统计结果，不是某个 Step 突然打开了一个能力开关。

## 先明确“规模”包括什么

本小节中的规模主要指：

- 模型见过多少训练 Token；
- 这些 Token 包含多少种上下文与规律；
- 参数经历多少次有效更新；
- 模型是否有足够参数容量吸收这些规律；
- 为这些过程投入多少训练计算。

这些量有关联，但不能混成同一个数字。更多重复低质量数据，也不必然等于更多有用能力。

参数量、数据量和计算量怎样配比，会在 [[../05-规模架构与能力形成/00-规模架构与能力形成概览|规模、架构与能力形成]] 中选读；本节只解释能力形成的主线。

## 一个贯穿例子

模型不会只见到一句：

```text
猫喜欢吃鱼。
```

它还会见到大量不同形式：

```text
小猫正在吃鱼。
有些猫更喜欢湿粮。
The cat ate the fish.
鱼被猫叼走了。
```

这些句子不完全相同，却共享词义、语法、角色关系和上下文模式。为了同时降低它们的预测 Loss，模型更需要形成可复用的内部规律，而不只是保存一份固定句子。

## 本节不会做的事

- 不把参数描述成一个可直接检索的事实数据库；
- 不声称每项知识都能定位到某一个参数或某一层；
- 不把低 Training Loss 等同于事实可靠；
- 不把模式泛化直接等同于意识或人类式理解；
- 不在这里展开 Scaling Law 的公式、算力预算或分布式训练。

## 学完后的判断标准

你应该能够解释：

1. 为什么“只预测下一个 Token”并不意味着模型只能学习相邻词频；
2. 为什么单个样本不会独自决定某个参数的含义；
3. 参数与运行时 Hidden State 在能力形成中分别扮演什么角色；
4. 为什么生成一个正确新答案，既不一定是原文记忆，也不能自动证明真正推理。
