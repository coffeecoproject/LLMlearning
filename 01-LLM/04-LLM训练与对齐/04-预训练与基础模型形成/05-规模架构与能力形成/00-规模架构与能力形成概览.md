# 规模、架构与能力形成概览

> [!summary]
> 模型能力受参数规模、有效数据、训练计算和架构效率共同影响；规模扩大通常带来可预测趋势，但不会保证每项能力同步或突然可靠。

## 四个学习问题

1. [[01-参数规模数据规模与训练计算为什么要配合|参数规模、数据规模与训练计算为什么要配合]]：区分模型容量、学习材料和实际训练过程；
2. [[02-Scaling-Law应该怎样理解|Scaling Law 应该怎样理解]]：理解可预测趋势、收益递减和计算最优的边界；
3. [[03-Dense与MoE怎样影响模型容量|Dense 与 MoE 怎样影响模型容量]]：区分总参数、激活参数与条件计算；
4. [[04-能力涌现是真的突然出现吗|能力涌现是真的突然出现吗]]：区分真实能力变化、任务门槛和评测阈值效应。

## 一条主线

```text
参数规模提供表示容量
+ 数据规模提供学习信号
+ 训练计算执行参数更新
→ 平均预测能力通常随规模改善

Dense 或 MoE
→ 决定容量与每 Token 计算怎样连接

具体任务跨过评分或可用门槛
→ 可能表现为“能力涌现”
```

规模只能提高形成能力的机会，不能单独保证事实正确、行为安全或工程任务可靠完成。

## 边界

这里解释结构与能力关系；设备并行、通信和显存分片进入 [[00-规模化训练系统概览|规模化训练系统]]。

- 参数量不是知识条目数量，也不是智能单位；
- Scaling Law 是特定实验条件下的经验关系，不是能力保证公式；
- Dense 与 MoE 的架构细节已在 [[00-FFN扩展结构概览|FFN 扩展结构]] 介绍，本节不重复计算；
- 能力涌现属于评测与机制解释问题，不能直接证明意识；
- OpenAI 闭源模型未公开的训练规模和架构细节不能从表现反推。

## 理解检查

1. 为什么只有参数量扩大，模型仍可能训练不足？
2. 为什么总参数不能直接代表 MoE 的每 Token 计算？
3. 为什么任务得分突然上升，不一定表示内部能力突然产生？
