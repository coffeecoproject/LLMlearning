# 训练刚开始时模型能做什么

> [!summary] 一句话理解
> 刚初始化的模型已经能完成 Token 到 Logits 的整条计算，但参数还没有从数据中学到语言规律，所以输出通常没有意义。

## 所属阶段

**从头预训练的最初阶段。** 这里讨论的不是已经下载好的 Base Model；后者已经完成大量预训练。

## 它为什么已经能够运行

程序已经拥有模型结构和初始参数，因此可以执行完整 Forward：

```text
文本
→ Tokenizer
→ Token IDs
→ Embedding
→ Transformer Blocks
→ Hidden States
→ LM Head
→ Logits
```

所以“未训练”不等于“程序不能计算”。它已有 Attention、FFN、Residual、Normalization、Causal Mask 和输出层；缺少的是这些参数从数据中形成的有用关系。

## 第一次预测会是什么样

假设教学词表只有四个 Token：

```text
苹果、汽车、因为、<EOS>
```

输入“我 喜欢”后，未训练模型也能给四个 Token 产生 Logits。但这些分数没有经过语言数据塑造，模型没有可靠理由让“苹果”稳定排在更合适的位置。

继续生成时，可能出现：

```text
汽车 <EOS> 因为 苹果……
```

这只是直观示意。准确说法不是“每个 Token 必然完全等概率”，而是“概率分布尚未与真实语言规律对齐”。

## 为什么不能只说它在随机输出

这里要区分两种不同现象：

1. **参数尚未训练**：Logits 缺少可靠语言意义；
2. **生成时采样**：运行程序按概率随机选择 Token。

初始化完成后，在参数更新前，同一组参数会被重复使用。即使采用确定性的最高分选择，未训练模型也可能稳定地产生没有语言意义的结果。

因此“没有学会语言”不等于“每次 Forward 都重新随机参数”。

## 第一批训练数据怎样改变它

```text
未训练模型的预测
→ 与真实下一个 Token 比较
→ 得到 Loss
→ Backward 计算 Gradient
→ Optimizer 轻微修改参数
```

第一步更新只造成很小变化，不会让模型突然学会中文、数学或世界知识。

随着大量样本重复提供信号，模型可能先形成常见 Token 频率、标点、空格、短语和局部格式，再逐渐形成更长距离和更抽象的关系。这是帮助理解的总体趋势，不是所有模型都遵循完全相同的固定阶段。

## 架构与训练分别提供什么

| 来源 | 主要提供 |
|---|---|
| 架构 | 信息怎样流动、位置能看到什么、参数怎样参与计算 |
| 训练 | 参数最终形成哪些语言、知识、代码和任务规律 |

同一种 Transformer 架构，用不同数据与训练配方，可以形成能力明显不同的模型。

## 从未训练模型到 Chat Model

```text
刚初始化
→ 可计算 Logits，但没有可靠语言能力
→ 大规模预训练
→ Base Model：形成续写、知识与一般模式能力
→ 指令和偏好后训练
→ Chat / Instruct Model：更倾向于遵循用户指令
```

因此 Base Model 不是“训练时间更长的 Chat Model”；Chat Model 还经历了目标和数据角色不同的后训练。

## 选读：初始 Loss 的数学直觉

如果教学词表只有 100 个 Token，并且模型近似给每个 Token `1%` 概率：

```text
正确 Token 概率 ≈ 0.01
Loss = -log(0.01) ≈ 4.6
```

词表越大，近似均匀分布时正确 Token 的概率越低，初始 Loss 通常越高。这只是理想化参考；真实数值还受初始化、Tokenizer、Mask 和模型实现影响。

## 常见误解

### 未训练模型不能执行 Forward

可以执行，只是结果尚无可靠能力。

### 初始输出无意义，是因为参数每轮都会重置

不是。参数会保留到下一次 Optimizer 更新。

### 第一次更新后，模型就记住了整个 Batch

不是。一次更新只是大量参数的微小联合变化。

### 架构先进就不再需要大量训练

不是。架构定义学习方式，具体能力仍由数据、目标、更新和规模共同塑造。
