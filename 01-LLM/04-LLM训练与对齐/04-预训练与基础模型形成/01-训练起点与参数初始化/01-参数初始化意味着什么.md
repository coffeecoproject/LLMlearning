# 参数初始化意味着什么

> [!summary] 一句话理解
> 参数初始化是在从头预训练开始前，由程序为模型参数设置起始数值；它提供可训练的起点，但还没有写入语言和知识。

## 所属阶段

**从头预训练的起点，选读机制。** Continued Pretraining、Fine-tuning 或 LoRA 通常从已有权重继续，不会把全部模型重新随机初始化。

## 初始化前已经有什么

训练团队已经先确定模型结构，例如：

- Tokenizer 与 Vocabulary；
- Transformer 层数、Hidden Size 和 Attention 结构；
- FFN、Normalization、Position 机制和 LM Head；
- 参数是否共享，以及每个参数张量的形状。

因此，参数“放在哪里、共有多少”已经确定；尚未形成的是参数中的语言规律。

## 初始化实际做什么

训练程序按照预先设定的规则，为参数张量写入较小的起始数值。教学上可以想象：

```text
[[ 0.01, -0.02,  0.00],
 [-0.01,  0.03,  0.02]]
```

这些数字只是示意，不是真实模型权重。

完整过程是：

```text
人和模型实现确定初始化规则
→ 程序生成起始数值
→ 写入参数张量
→ 数据进入模型
→ Gradient 与 Optimizer 开始改变参数
```

所以初始化由程序完成；模型随后才通过训练形成能力。

## 为什么不能把所有权重设成一样

如果同一层中需要分工的通道拥有完全相同的参数，并收到相同 Gradient，它们可能一直做相同的事，难以学习不同模式。

适当不同的初值可以打破这种对称，让不同通道逐渐分工。

这不等于所有参数都必须随机且不能为零。某些 Bias 或缩放参数可以使用特殊初值；关键是整体初始化配方要让网络可训练。

## 为什么还要控制数值大小

Transformer 有许多层。初值太大或尺度不合适时，中间表示和 Gradient 可能过大、过小或不稳定，使训练难以开始。

因此初始化同时做两件事：

1. 让不同参数能够逐渐分工；
2. 让信号经过深层网络时保持在较可控的范围。

这里不需要记忆具体分布公式。

## Random Seed 是什么

Random Seed（随机种子）控制伪随机数生成过程。相同代码、配置和 Seed 通常能生成相同初值，便于复现实验。

它不表示模型每次收到 Prompt 都重新随机参数。初始化完成后，参数会保持不变，直到 Optimizer 更新它们。

## 开放模型观察：Qwen2.5-7B

Qwen2.5-7B 的公开配置包含：

```json
{
  "hidden_size": 3584,
  "num_hidden_layers": 28,
  "vocab_size": 152064,
  "initializer_range": 0.02
}
```

- 前三个字段帮助确定参数结构与规模；
- `initializer_range` 是创建未训练模型时使用的初始化配置之一；
- Hugging Face 发布的模型权重已经完成预训练，不再是随机初值；
- 这个字段不能代表训练完成后的参数分布，也不能推断闭源模型配置。

来源：[Qwen2.5-7B 官方模型卡](https://huggingface.co/Qwen/Qwen2.5-7B)、[Qwen2.5-7B config.json](https://huggingface.co/Qwen/Qwen2.5-7B/blob/main/config.json)，核对日期：2026-07-28。

## 常见误解

### 初始化就是给模型写入基础知识

不是。它只提供数值起点；知识来自后续数据和参数更新。

### 随机参数表示模型没有结构

不是。模型结构和计算规则已经存在，只是参数尚未形成有用关系。

### 所有训练都从随机参数开始

不是。继续预训练和微调通常加载已有 Checkpoint。
