# 完整预训练案例与边界概览

> [!summary]
> 本部分把初始化、训练数据、更新、能力形成和 Base Model 串成完整案例，并用开放模型资料校验哪些技术设定真正公开。

## 四个学习问题

1. [[01-从初始参数到Base-Model完整走一遍|从初始参数到 Base Model 完整走一遍]]：把前面的概念连接成一条因果链；
2. [[02-模型卡技术报告配置文件和权重分别能证明什么|模型卡、技术报告、配置文件和权重分别能证明什么]]：建立公开资料的证据层级；
3. [[03-用Llama-3重建一次公开的预训练案例|用 Llama 3 重建一次公开的预训练案例]]：把官方披露放回完整训练路径；
4. [[04-预训练能形成什么又不能保证什么|预训练能形成什么，又不能保证什么]]：区分基础能力、指令行为、事实可靠性和系统执行能力。

## 一条完整主线

```text
确定目标与架构
→ 构建 Tokenizer 和训练数据
→ 初始化模型参数
→ 反复执行 Forward、Loss、Backward、Optimizer Step
→ 用评估与 Checkpoint 观察训练
→ 长期累积形成基础能力
→ 得到 Base Model
→ 后训练塑造 Chat / Instruct 行为
→ Runtime 部署
→ Agent 连接工具和工作流
```

这条主线把“模型训练完成”放在完整系统中的正确位置：它是基础，但不是可靠产品的终点。

## 边界

案例以理解因果链为目的，不把训练命令、集群部署或完整数学推导作为必读内容。

- “完整”指学习路径完整，不代表厂商公开了完整数据和训练代码；
- 模型权重可以运行，不等于训练过程可以完全复现；
- 模型卡中的事实只适用于明确版本；
- 开放权重不自动等于开放数据、开放训练代码或开放许可证；
- Llama、Qwen、DeepSeek 或 `gpt-oss` 的公开事实不能直接外推到 OpenAI 闭源 GPT 模型；
- 多卡训练、容错和 Checkpoint 工程进入下一部分 [[00-规模化训练系统概览|规模化训练系统]]。

## 理解检查

1. 为什么下载到权重仍不等于知道模型怎样训练出来？
2. `config.json` 能证明什么，不能证明什么？
3. Base Model 为什么可能会续写，却不稳定遵循用户指令？
