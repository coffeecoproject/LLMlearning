# 预训练与基础模型形成概览

> [!summary]
> 预训练从尚未形成能力的参数出发，在大规模数据上反复执行下一 Token 预测和参数更新，逐渐形成可复用的语言、知识、代码与组合能力。

## 从一次更新到完整预训练

```text
一次参数更新
→ 大量不同 Batch
→ 大量 Training Step
→ 参数持续变化
→ 形成基础能力
→ 得到 Base Model
```

一次更新只反映当前 Batch 的局部信号；能力来自大量数据和长期更新的共同结果。

## 预训练主要改变什么

训练会更新 Embedding、Attention、FFN 和输出层等模型参数。Tokenizer 映射、层数和 Hidden Size 通常在一次既定训练中保持不变。

```text
固定结构 + 变化的参数
→ 相同 Forward 机制逐渐产生更有意义的概率分布
```

## Base Model 在哪里出现

```text
初始参数
→ 大规模预训练
→ Base Model
→ SFT、偏好优化或强化学习
→ Chat / Instruct Model
```

Base Model 可能已经具有很强的续写、知识和代码能力，但基础目标并不自动保证稳定服从用户指令。

## 边界

- 数据清理和 Packing 已在训练数据部分介绍，不在这里重讲；
- Loss、Backward 和 Optimizer 已在参数更新部分介绍；
- 多卡、显存和训练恢复归入规模化训练系统；
- SFT、RLHF 和 DPO 归入后训练与行为对齐；
- 形成有用内部表示，不等于已经证明模型具有类人意识；
- 开放模型的具体配置不能直接外推为 OpenAI 闭源模型内部设定。
