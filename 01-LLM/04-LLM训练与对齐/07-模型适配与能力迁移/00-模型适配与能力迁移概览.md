# 模型适配与能力迁移概览

> [!summary]
> 模型适配是在已有基础模型上，根据领域、任务、成本或部署目标选择更新全部参数、少量新参数，或将能力迁移到另一个模型。

## 本专题将学习

- Continued Pretraining 与领域语料适应；
- Full Fine-tuning；
- LoRA 与 PEFT；
- 蒸馏与教师—学生能力迁移；
- 任务适配、能力保留和灾难性遗忘；
- 什么情况适合 Prompt、RAG、工具、微调或组合方案。

## 边界

LoRA 是一种参数高效适配方法，不要与 MLA 配置中表示低秩投影的 `q_lora_rank` 或 `kv_lora_rank` 混淆。
