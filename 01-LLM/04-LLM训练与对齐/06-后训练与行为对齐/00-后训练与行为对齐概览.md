# 后训练与行为对齐概览

> [!summary]
> 后训练不只是给模型“增加知识”，更重要的作用是用指令、偏好、奖励和任务轨迹塑造模型倾向于如何回应和行动。

## 本专题将学习

1. Base Model 为什么不等于 Chat Model；
2. SFT 怎样学习指令、回答格式和工具调用；
3. 偏好数据、Reward Model 和 RLHF 的作用关系；
4. DPO 与 RLHF 的共同目标和机制差别；
5. RLVR 怎样利用可验证结果塑造推理与执行；
6. Reasoning Effort、长轨迹和 Agent 环境怎样进入训练；
7. 对齐为什么改变行为倾向，却不能自动保证事实正确。

## 边界

模型可在训练中学习生成工具调用和长任务策略，但运行时的真实工具执行、状态保存和验证仍由 Agent Harness 与外部系统承担。
