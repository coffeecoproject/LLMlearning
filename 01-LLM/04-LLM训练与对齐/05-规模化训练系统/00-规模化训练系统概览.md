# 规模化训练系统概览

> [!summary]
> 当模型、样本和训练状态无法放入一张计算卡时，训练系统必须把数据、参数、计算和状态分配到多设备，同时尽量保持与目标训练等价。

## 本专题定位

这是选读的训练工程层，只要求理解“在拆什么、为什么必须拆、代价是什么”：

- 混合精度与训练状态内存；
- Gradient Accumulation；
- Data Parallelism；
- Tensor Parallelism；
- Pipeline Parallelism；
- Expert Parallelism 与 MoE 负载均衡；
- Checkpoint、故障恢复与数值稳定性。

不把 GPU 通信公式、Kernel 编程或集群部署命令作为必读内容。
