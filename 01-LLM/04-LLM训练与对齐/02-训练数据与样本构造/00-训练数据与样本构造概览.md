# 训练数据与样本构造概览

> [!summary]
> 原始资料要经过筛选和组织，再由固定 Tokenizer 变成长度合适、目标明确的 Token 序列，才会成为模型真正学习的训练样本。

## 本专题处于哪里

```text
网页、书籍、代码、论文等资料
→ 【本专题】训练样本
→ Forward、Loss 与参数更新
```

这里属于 **训练数据准备阶段**：使用 Tokenizer，但不重新训练 Tokenizer，也还没有更新 LLM 参数。

## 必须理解的主线

```text
原始资料
→ 过滤明显无效或不应使用的内容
→ 去重并决定不同数据的比例
→ 固定 Tokenizer 编码
→ 处理长度和文档边界
→ 得到 Token 序列与预测目标
→ 组成训练 Batch
```

核心不是记住字段名，而是理解：**模型只会从最终真正进入训练样本的数据分布中获得信号。**

### 1. [[00-数据准备概览|数据准备]]

### 3. [[00-训练样本字段与完整案例概览|样本字段与完整案例]]（选读）

## 一个简化例子

```text
原文：苹果是一种水果。
→ Tokenizer
→ [苹果] [是] [一种] [水果] [。] [EOS]
→ 模型在多个位置学习预测后一个 Token
```

真实训练还要处理数据质量、长度、边界和批量组织，但不需要先掌握这些实现细节才能理解参数更新。

## 数据为什么影响能力

```text
某类数据出现得更多
→ 提供更多相关预测目标
→ 参数获得更多这类训练信号
→ 相关能力可能更强
```

但数量不是唯一因素。质量、重复度、模型容量、训练目标和其他数据都会影响最终结果。
