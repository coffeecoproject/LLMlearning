## 先看最终对象

一条简化训练样本可能表现为：

```text
input_ids:      [21, 35, 48,  2,  0]
attention_mask: [ 1,  1,  1,  1,  0]
labels:         [21, 35, 48,  2, -100]
```

> [!example] 教学示意
> 数字只是为了说明字段关系，并非任何真实模型的 Token ID。

直觉上：

- `input_ids` 提供模型实际读取的 Token；
- `attention_mask` 标记哪些位置是有效输入、哪些是补齐位置；
- `labels` 提供训练目标，并常用特殊忽略值排除不计算 Loss 的位置；
- Causal Mask 仍由模型结构或训练实现另外保证，不能与 `attention_mask` 混为一谈。

## 边界

- 字段名称和张量形式会因框架、模型和训练配方变化；概念职责比某个库的字段名更稳定。
- 有的实现显式保存 `loss_mask`，有的只把相应 `labels` 改为 `-100` 等忽略值。
- 有的实现预先错位 Labels，有的把 `labels` 设为与输入相同并在模型内部错位；概念上都在学习下一个 Token。
- 这些样本字段只准备了训练输入，还没有执行 Loss、Backward 或 Optimizer 更新。
