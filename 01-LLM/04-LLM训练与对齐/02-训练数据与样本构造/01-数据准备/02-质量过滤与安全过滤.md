# 质量过滤与安全过滤

> [!summary]
> 过滤不是判断一篇文本“绝对好或坏”，而是按训练目标排除明显有害、无效或风险过高的内容，并给剩余数据分层或赋权。

## 为什么原始数据不能直接使用

原始网页、代码和文档里常混有：

- 菜单、广告、Cookie 提示和重复页脚；
- 乱码、截断文本和扫描识别错误；
- 关键词堆砌、自动生成的低信息页面；
- 无法解析或明显损坏的代码；
- 个人敏感信息、凭据、密钥和内部内容；
- 极端危险、违法或与项目政策冲突的内容。

如果这些内容大量进入训练，它们会消耗计算预算，并反复成为模型的预测目标。

## 先区分三类处理

### 1. 解析与格式清理

目标是从文件或网页中提取真正内容：

```text
HTML 页面
→ 去除导航栏、脚本和广告
→ 保留标题、正文和结构
```

它主要处理载体噪声，不直接判断观点是否正确。

### 2. 质量过滤

目标是估计内容是否值得占用训练预算。例如：

- 文本是否完整、连贯并具有足够信息；
- 代码是否有合理结构；
- 语言识别是否可信；
- 模板、符号或重复短句占比是否过高；
- 内容是否与目标领域匹配。

### 3. 安全、隐私与政策过滤

目标是降低不应进入训练的数据风险。例如：

- 个人敏感信息；
- API Key、密码和私有凭据；
- 未经许可的内部文档；
- 项目政策明确排除的危险或违法内容。

质量高不代表安全合适，安全合适也不代表训练价值高。

## 过滤可以怎样实现

真实管线可能组合：

| 方法 | 直白理解 | 局限 |
|---|---|---|
| 确定性规则 | 按长度、字符比例、文件类型等硬条件处理 | 容易误删特殊但有价值的内容 |
| 启发式规则 | 使用经验阈值判断模板、乱码和低信息页面 | 阈值依赖数据与语言 |
| 分类器 | 由专门模型判断语言、质量或风险类别 | 分类器本身也会犯错和带偏差 |
| LLM 评审 | 用模型评分、改写或生成质量标签 | 成本更高，也可能复制评审模型偏好 |
| 人工抽检 | 人检查样本和过滤结果 | 难以覆盖超大规模数据 |

合理做法通常是多层组合，并持续抽样检查“保留集”和“删除集”。

## 为什么过滤不能越严格越好

如果规则只保留正式、标准、百科式文本，模型可能失去：

- 日常语言和口语表达；
- 少数语言、方言或小众领域；
- 真实世界中不整齐但有价值的代码和问题；
- 对错误内容进行识别和纠正所需的样本。

所以过滤要平衡：

```text
降低噪声和风险
↔
保持多样性、覆盖面与真实分布
```

## 开放模型观察：Llama 3

Meta 的 Llama 3 官方说明把启发式过滤、NSFW 过滤、语义去重和文本分类器都列入数据管线，并通过小规模训练实验选择数据混合。

这说明真实模型不会依赖单一“质量分数”；数据选择通常是规则、分类模型、去重和训练实验的组合。

来源：[Introducing Meta Llama 3](https://ai.meta.com/blog/meta-llama-3/)、[The Llama 3 Herd of Models](https://ai.meta.com/research/publications/the-llama-3-herd-of-models/)，核对日期：2026-07-28。

## 常见误解

- **“过滤就是删掉观点错误的文本。”** 过滤还包括解析噪声、格式、隐私、凭据、质量和政策边界。
- **“一个大模型评分就够了。”** 评审模型也存在错误、成本和偏好，仍需规则与抽检。
- **“过滤越狠，模型越聪明。”** 过度过滤会造成数据单一和覆盖不足。
- **“安全过滤后模型就不会产生危险内容。”** 数据过滤只是安全系统的一部分，不能替代后训练、评估和运行防护。
