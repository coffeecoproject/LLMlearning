# 数据准备概览

> [!summary]
> 数据准备的目的不是把资料“洗得越多越好”，而是在可追溯、可使用和质量可控的前提下，形成与模型目标匹配的数据分布。

## 本小节的主线

```text
候选来源
→ 记录来源、时间、许可和处理版本
→ 解析正文与格式标准化
→ 质量、安全、隐私和语言过滤
→ 精确与近似去重
→ 排除评测污染
→ 按领域与语言混合、采样
→ 得到可编码的训练语料库
```

## 为什么不能只做一个“干净/不干净”判断

同一份资料可能在不同维度得到不同结论：

| 维度 | 示例问题 |
|---|---|
| 权利与政策 | 是否允许用于目标用途，是否受许可或条款限制 |
| 技术质量 | 是否乱码、截断、模板占比过高或代码无法解析 |
| 内容质量 | 是否信息稀薄、逻辑混乱、机器堆砌或广告密集 |
| 隐私与安全 | 是否包含个人敏感信息、密钥或危险内容 |
| 重复程度 | 是否与已有内容完全或高度相似 |
| 任务价值 | 是否能补充目标语言、领域、推理或代码能力 |

因此真实管线通常包含多道规则和模型，而不是一个万能过滤器。

## 边界

- 数据准备发生在模型参数更新之前；过滤程序本身不是 LLM 训练。
- “公开可访问”不自动等于“可在任何条件下训练”，具体使用仍要审查来源、许可、条款与适用规则。
- 删除低质量数据不保证模型一定正确；保留下来的数据仍可能含有偏差、冲突和过时知识。
- 某些训练流程会迭代调整数据混合，但这不表示普通用户对话会直接写回训练集。
