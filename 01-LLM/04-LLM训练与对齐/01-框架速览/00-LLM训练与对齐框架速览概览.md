# LLM 训练与对齐框架速览

> [!summary]
> 训练让模型先用当前参数预测，再根据预测偏差反复小幅调整参数；大量更新形成基础能力，后训练继续塑造行为。

## 最直白的理解

训练文本提供“真实后续”，模型提供“当前预测”：

```text
输入：今天天气很
真实后续：好
模型当前更倾向：冷
```

训练系统把差异转成 Loss，再计算参数应怎样调整。它不是把整句话保存成一条数据库记录。

## 一次训练更新

```text
训练文本
→ 固定 Tokenizer 得到 Token ID
→ 构造下一 Token 目标
→ Forward 得到 Logits
→ Loss 衡量偏差
→ Backward 得到 Gradient
→ Optimizer 更新参数
```

一次更新只产生很小影响。模型能力来自大量不同数据和 Training Step 的共同作用。

## 训练与普通运行从哪里分开

```text
共同部分：Token ID → Transformer → Logits

训练：Logits → Loss → Backward → 参数更新
运行：Logits → 选择 Token → 继续生成，参数不变
```

所以，与模型对话一般不会让它当场修改参数。

## 先区分三个阶段

| 阶段 | 主要目标 | 典型结果 |
|---|---|---|
| 预训练 | 学习广泛的下一 Token 规律 | Base Model |
| 后训练与对齐 | 学习指令、偏好、推理或工具行为 | Chat / Instruct Model |
| 模型适配 | 面向领域、任务或成本继续调整 | 领域模型、Adapter 或蒸馏模型 |

三者都可能更新参数，但使用的数据、目标和期望行为不同。

## 哪些东西通常会改变

训练通常改变 Embedding、Attention、FFN 和输出层等模型参数。Tokenizer 映射、模型层数和 Hidden Size 等通常在一次既定训练中保持不变。

不同训练方式可能只更新部分参数；这属于后面的模型适配内容。

## 常见误解

- 训练不是把文档原样存入模型；
- 普通回答不会自动触发 Backward；
- Loss 只提供优化目标，不直接写出新参数；
- 已知训练后续不等于 Attention 可以读取未来；
- Base Model 有基础能力，不等于已经稳定听从指令。
