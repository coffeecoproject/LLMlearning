# LLM 模块大纲

## 模块定位

LLM 是整套学习的基础模块。本模块先研究模型本身，再进入后续的推理与 CoT、Agent、持续学习和更高级智能系统。

本模块需要建立一条完整因果链：

```text
模型由什么构成
→ 训练完成的模型如何运行
→ 训练如何改变模型
→ 能力为什么形成
→ 能力为什么存在边界
→ 怎样评估、优化并理解模型演进
```

## 核心问题

> 一个通过大量数据和预测目标训练出来的模型，怎样形成语言与知识能力，并在运行时根据上下文生成有用但不一定可靠的结果？

## 五部分结构

```text
第一部分  模型基础与静态结构
          ↓
第二部分  LLM 普通运行与生成
          ↓
第三部分  LLM 训练与对齐
          ↓
第四部分  能力形成与边界
          ↓
第五部分  评估、优化与模型演进
```

第二部分和第三部分研究不同阶段，但教学顺序保持线性：

- 第二部分研究一个已经训练完成的模型怎样运行；
- 第三部分研究模型参数和行为倾向怎样形成；
- 先理解固定参数的运行，避免把聊天过程误认为参数训练；
- 第四部分把两条路线重新连接，解释实际能力和失败；
- 第五部分研究怎样测量、改进和比较模型。

### 定位

## 第二部分：LLM 普通运行与生成

> [!map]
> 详细结构见 [[01-LLM/02-LLM普通运行与生成/LLM普通运行与生成大纲|LLM 普通运行与生成大纲]]。

### 定位

回答“训练完成的模型怎样被运行、怎样接收上下文并逐步产生输出”。这里的推理指 `Inference`，即运行模型，不等同于后续 CoT 模块研究的逻辑推理能力。

### 一级大纲

1. Inference 的含义与完整生命周期
2. Prompt、消息与模型真实输入
3. 上下文窗口与运行时状态
4. 前向计算与概率输出
5. 解码与逐 Token 生成
6. 随机性、稳定性与可复现性
7. 多轮交互与上下文管理
8. 结构化输入输出与模型接口
9. 推理成本、延迟与资源占用
10. 本地运行、服务调用与部署形态

### 本部分结束时应能回答

> 当用户发送一条消息后，系统和模型分别做了什么，最终回答为什么是一个 Token 接一个 Token 出现的？

## 第三部分：LLM 训练与对齐

> [!map]
> 详细结构见 [[01-LLM/03-LLM训练与对齐/LLM训练与对齐大纲|LLM 训练与对齐大纲]]。

### 定位

回答“模型参数、基础能力和行为倾向怎样形成”。训练决定模型能够学到什么，后训练和对齐进一步塑造模型倾向于怎样回应。

### 一级大纲

1. 训练到底在改变什么
2. 数据、样本与训练目标
3. 前向计算、误差与参数更新
4. 预训练与基础能力形成
5. 数据规模、模型规模与计算规模
6. 后训练的目的和主要阶段
7. 指令学习与任务适应
8. 偏好学习与行为对齐
9. 强化学习、可验证反馈与其他路线
10. Fine-tuning、蒸馏与模型适配
11. 训练数据质量、偏差与污染
12. 训练稳定性、遗忘与能力权衡

### 本部分结束时应能回答

> 为什么基础模型、指令模型和经过不同对齐方法处理的模型，会在相同输入下表现出不同的回答倾向？

## 第四部分：能力形成、表现与边界

> [!map]
> 详细结构见 [[01-LLM/04-能力形成与边界/能力形成与边界大纲|能力形成与边界大纲]]。

### 定位

把模型机制、运行方式和训练过程连接起来，回答“模型为什么能做这些事情，又为什么不能始终可靠地做到”。

### 一级大纲

1. 语言能力如何形成
2. 知识怎样进入并表现于模型
3. 上下文学习与临时适应
4. 指令理解与意图推断
5. 推理行为及其不同解释
6. 规模扩展与能力变化
7. 记忆、泛化与模式复现
8. 幻觉与事实不可靠
9. 长上下文与注意力退化
10. 提示敏感、指令冲突与输出波动
11. 数据偏差、知识时效与分布外问题
12. 模型能力、系统能力与外部工具的边界

### 本部分结束时应能回答

> 为什么同一个模型既能给出很有价值的答案，也会自信、流畅地生成错误内容？

## 五部分的边界

| 部分 | 主要研究对象 | 暂时不深入的内容 |
|---|---|---|
| 模型基础与静态结构 | 模型内部对象与计算结构 | 完整运行、参数更新与 Runtime 服务 |
| LLM 普通运行与生成 | 固定参数下的运行过程 | 参数训练、CoT 和复杂逻辑推理方法 |
| 训练、后训练与对齐 | 参数与行为倾向的形成 | Agent 的长期学习循环 |
| 能力形成、表现与边界 | 能力来源和失败机制 | Agent 系统可靠性设计 |
| 评估、优化与模型演进 | 测量、改进、比较与发展路线 | 对 AGI 的综合判断 |

## 开放模型观察原则

每一部分在适合时选择具体的开放权重模型版本进行观察，但不把某个模型的配置当成所有 LLM 的统一规律。

观察材料优先来自：

1. 官方 Model Card；
2. 官方代码仓库；
3. 对应版本的配置文件；
4. 官方技术报告。

所有版本敏感信息需要标明模型全名、来源与核对日期，并区分公开事实、合理推断和未知信息。

## LLM 模块完成标准

完成五部分后，应当能够：

1. 描述从文本输入到 Token 输出的完整模型链路；
2. 区分模型机制、Inference、训练、后训练和对齐；
3. 解释主要能力如何形成以及为什么不稳定；
4. 判断一个问题来自模型、上下文、训练、解码还是评估方式；
5. 阅读开放权重模型的基础配置和 Model Card；
6. 对模型能力、成本和风险做有证据的比较；
7. 带着准确的 LLM 心智模型进入 [[02-推理与CoT/推理与 CoT 模块大纲|推理与 CoT]] 模块。
