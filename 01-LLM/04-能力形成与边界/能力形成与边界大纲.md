# 能力形成与边界大纲

> 在模型结构、普通运行和训练三条主线分别建立之后，再解释语言、知识、上下文学习、推理表现与失败边界。本部分讨论“为什么会表现出这种能力”，不把行为表现直接等同于意识或可靠的内部符号推理。

1. `4.1` 语言能力如何从预测目标、数据和参数中形成；
2. `4.2` 知识怎样进入参数，又怎样通过上下文被触发和表达；
3. `4.3` In-context Learning 与临时适应：改变当前状态但不默认修改权重；
4. `4.4` 指令理解与意图推断：训练倾向、上下文约束与歧义；
5. `4.5` 推理表现及其不同解释，并与后续 CoT 模块划清边界；
6. `4.6` Scaling、能力变化与“涌现”证据怎样谨慎解读；
7. `4.7` 记忆、泛化、组合与模式复现的区别；
8. `4.8` 幻觉、不确定性、过度自信与概率校准；
9. `4.9` 长上下文：位置外推、信息利用退化和上下文不等于有效记忆；
10. `4.10` Prompt 敏感、指令冲突、随机性与输出波动；
11. `4.11` 数据偏差、知识时效、分布外输入与安全边界；
12. `4.12` 模型能力、Runtime、RAG、工具与 Agent 系统能力的边界。

## 核心防混淆

```text
训练中形成的参数能力
≠ 当前上下文临时提供的信息
≠ 解码策略造成的输出差异
≠ 外部工具或 Agent 提供的系统能力
```
