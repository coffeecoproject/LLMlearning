# 1.3.4 ALiBi 的作用位置与直觉

> [!summary]
> ALiBi（Attention with Linear Biases）不为每个位置添加输入向量，也不旋转 Q、K，而是根据 Token 间距离给 Attention Score 加上线性偏置。

## 它作用在哪里

Attention 会先使用 Q 和 K 为位置之间计算原始匹配分数：

```text
Q 与 K
→ 原始 Attention Score
```

ALiBi 在 Softmax 之前加入与距离相关的偏置：

```text
原始 Attention Score
+ 距离偏置
→ 调整后的 Score
→ Softmax
→ Attention Weight
```

所以 ALiBi 的位置非常明确：它修改 Score，不是修改输入 Embedding。

## “线性偏置”怎样理解

在 Causal Decoder 中，当前位置只能关注自己和过去位置。过去位置离当前越远，ALiBi 通常施加越大的负向距离惩罚。

教学示意：

```text
距离 0 → 偏置  0
距离 1 → 偏置 -m
距离 2 → 偏置 -2m
距离 3 → 偏置 -3m
```

`m` 是斜率。距离增加一单位，偏置按固定斜率线性变化，因此称为 Linear Bias。

> [!warning]
> 这只是结构示意。真实实现有多个 Attention Head，各 Head 可使用不同斜率，符号和距离写法也会因实现约定而不同。

## 为什么要让远处位置受到惩罚

自然语言中，邻近信息经常更直接相关。ALiBi 给模型加入一种归纳偏置：在内容匹配程度相近时，更近的位置通常更容易获得较高权重。

但这不是强制模型永远只关注附近。若远处 Token 的内容匹配分数足够强，仍可能抵消距离惩罚并获得注意力。

```text
最终 Score
= 内容相关性
+ 距离偏置
```

因此 ALiBi 是倾向，不是硬性截断。

## 多个 Head 为什么使用不同斜率

不同 Attention Head 使用不同斜率，可以形成不同的位置偏好：

```text
较陡斜率
→ 更强烈偏向附近位置

较缓斜率
→ 对远距离的惩罚较弱
```

这是理解多头分工的一种结构直觉，但不能断言每个 Head 都对应一个清晰、固定的人类功能。

## ALiBi 与 Causal Mask 的区别

```text
Causal Mask
→ 未来位置不允许被看见，属于硬约束

ALiBi
→ 对允许看见的位置按距离调整分数，属于软偏置
```

一个未来位置即使内容很相关，也会被 Causal Mask 排除；一个很远的过去位置受到 ALiBi 惩罚后，仍有可能被关注。

## ALiBi 与长上下文

ALiBi 不依赖为每个绝对位置保存一行位置向量，因此在结构上较容易把距离规则应用到更长序列。但能否在训练长度之外保持质量，仍需由具体模型、训练方式和评测结果证明。

```text
规则可以计算更远距离
≠ 模型在任意长文本上都可靠
```

## 常见误解

- **“ALiBi 是另一种 Position Embedding 查表。”** 它直接修改 Attention Score。
- **“ALiBi 会屏蔽所有远距离 Token。”** 它通常施加软惩罚，不是硬性删除。
- **“ALiBi 与 Causal Mask 功能相同。”** 一个表达距离偏好，一个限制未来可见性。
- **“线性规则可以无限计算，所以模型拥有无限上下文能力。”** 可计算不等于训练外表现可靠。
