# 为什么不能只保留子层新结果

> [!summary]
> 如果每个子层都必须独自重建全部表示，旧信息更容易在深层变换中被破坏；Residual 让子层主要学习“在原表示上改什么”，同时给旧表示保留直接通路。

## 用“接力改稿”理解

想象十个人依次修改同一份说明书。

没有 Residual 的直觉：

```text
每个人看完上一版
→ 必须从头交出一份完整的新说明书
→ 下一人只能看到这份新说明书
```

有 Residual 的直觉：

```text
当前完整版本一直沿主干传递
→ 每个人根据当前版本提交一次修改
→ 修改加入当前版本
→ 再交给下一人
```

第二种结构让每一步都可以专注于“这一次需要改变什么”，而不用让每个子层承担从零重建全部表示的压力。

> [!warning] 类比边界
> Transformer 各层不是具有独立意识的审阅者，也不会保留可读的版本历史。真实模型只有当前 Hidden State 和子层产生的数值结果；这个类比只解释直接通路为什么有用。

## 先看没有 Residual 的情况

假设一个 Block 直接这样更新：

```text
x → Attention(x) → FFN(Attention(x)) → 下一层
```

每经过一个子层，后续结构只能收到这个子层新算出的结果。即使 `x` 中已有一些有用信息，子层也必须在输出中重新表达它，否则这些信息就可能减弱或丢失。

对于只有一两层的小系统，这未必立刻表现成明显问题；但 LLM 会堆叠很多 Transformer Block，连续重写会使“既保留已有信息，又增加新变化”的任务更困难。

## Residual 把“重写”变成“增量更新”

加入 Residual 后：

```text
y = x + F(x)
```

子层可以把计算重点放在 `F(x)`：

```text
x 已经有的内容
+ 当前子层认为需要加入的变化
= 更新后的表示
```

这不代表模型永远原样保留旧信息。`F(x)` 可以包含正数、负数和复杂方向的变化，后续层也会继续修改表示。Residual 提供的是直接通路和更新方式，不是不可删除的备份。

## 有和没有 Residual 的直接对比

| 问题 | 没有 Residual | 有 Residual |
|---|---|---|
| 下一步收到什么 | 只有子层新输出 `F(x)` | `x + F(x)` |
| 想保持近似不变 | 子层需要自己重建 `x` | 让 `F(x)` 接近 0 即可 |
| 旧表示有没有直接路径 | 没有 | 有 |
| 是否保证绝不丢信息 | 不保证 | 仍然不保证 |
| 运行时是否还要执行 | 不适用 | 要执行，属于模型结构 |

最关键的一行是：Residual 提供了保留旧表示的**可能性和直接路径**，但没有把旧信息永久锁死。

## 一个简化例子

假设当前位置的旧表示是：

```text
x = [1.0, 2.0, 1.0]
```

当前子层只需要做一个较小调整：

```text
F(x) = [0.1, 0.0, -0.2]
```

有 Residual：

```text
y = [1.1, 2.0, 0.8]
```

如果没有 Residual，子层想得到相同结果，就必须自己完整输出：

```text
F(x) 必须直接变成 [1.1, 2.0, 0.8]
```

这个小例子不证明模型总是只做微小调整，但展示了 Residual 提供的结构选择：子层可以学习完整重写，也可以更方便地学习相对于输入的变化。

## 如果当前子层暂时不需要改变什么

Residual 还提供了一个重要可能性。假设某个子层对当前输入产生接近零的变化：

```text
F(x) ≈ [0,0,0]
```

那么：

```text
y = x + F(x) ≈ x
```

当前表示可以近似原样通过这一子层。没有直接通路时，子层若想“什么都不改”，就必须自己学出接近恒等映射，也就是把输入完整重建出来。

> [!note]
> 真实模型中的 `F(x)` 不一定很小，也不保证某层等于恒等映射。这里说明的是 Residual 允许这种行为，而不是断言所有层都这样工作。

## 为什么这对很多层特别重要

多个 Block 堆叠后，可以把数据流直觉理解为：

```text
x₀
→ x₁ = x₀ + 第1层变化
→ x₂ = x₁ + 第2层变化
→ x₃ = x₂ + 第3层变化
→ ……
```

每层都在上一层结果上继续更新。这样既保留连续的数据主干，也允许不同层逐步组合更复杂的上下文信息。

但是不要把这张图理解为“最终表示就是所有层结果的普通总和”。每层的变化都依赖当时的 Hidden State，层与层之间还存在 Normalization、Attention、FFN 和非线性计算。

## 训练阶段为什么也需要直接通路

> [!info] LLM 训练阶段
> 训练不只要把数据向前传，还要把 Loss 产生的学习信号向前面的层传播。Residual 提供的直接通路有助于学习信号穿过深层网络，降低深层结构难以优化的问题。

这里先保留直觉：

```text
前向：旧表示有直接通路
反向：学习信号也多了一条直接通路
```

为什么数学上成立，需要用导数和反向传播解释，放到 LLM 训练模块再学习。本节不把“有助于训练”夸大成“保证训练一定稳定”；Normalization、初始化、优化器和数据等也会影响训练。

## 普通运行阶段还需要吗

> [!info] LLM 运行阶段
> 需要。运行时虽然不计算梯度、不更新参数，但模型已经被训练成依赖这套结构。删除 Residual 会改变每层收到的 Hidden State，使模型不再是原来训练好的模型。

因此 Residual 不能被视为“只为训练服务、推理时可以关掉”的辅助部件。

## 常见误解

- **“Residual 会让旧信息永远无法删除。”** 后续变化仍可减弱、抵消或重组旧表示。
- **“每层只学习很小的修正。”** Residual 允许增量学习，但不保证实际变化一定很小。
- **“有了 Residual，信息绝不会丢失。”** 它改善直接传递条件，不提供绝对的信息保存保证。
- **“Residual 只在训练时有用。”** 它属于训练和运行共同使用的模型前向结构。
- **“Residual 单独解决了深层训练的一切问题。”** Norm、初始化、优化方法等同样重要。
