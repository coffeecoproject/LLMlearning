# 模型怎样比较当前位置与其他位置

> [!summary]
> 当前接收位置使用自己的 Query，分别与每个允许候选位置的 Key 比较，从而得到“这个来源对我有多匹配”的分数。

## 用代词理解匹配

```text
小明把书交给小红，因为她明天要考试。
```

处理“她”时，模型需要分别比较前面的候选位置：

```text
“她”的 Query ↔ “小明”的 Key
“她”的 Query ↔ “书”的 Key
“她”的 Query ↔ “小红”的 Key
```

每次比较都会产生一个匹配分数。分数较高表示在当前层、当前 Head 的这次计算中，更适合作为信息来源。

## 不是从中挑出唯一答案

Attention 不必立刻作出：

```text
只选择“小红”，删除其他位置
```

它先为所有允许位置保留不同强弱，后面再转换为相对权重。因此多个位置可以共同贡献信息。

## 匹配是动态的

同一个来源位置面对不同 Query，会得到不同分数。Attention 计算的不是 Token 的全局重要性，而是：

```text
这个来源位置
对于这个接收位置
在当前层和当前 Head 中
有多匹配
```

## 可选技术补充：点积

真实 Transformer 通常使用 Q 与 K 的点积作为基础匹配方法。两个等长向量对应数字相乘后求和：

```text
[1, 2] · [3, 4] = 1×3 + 2×4 = 11
```

这个例子只展示计算形式。点积发生在模型学习得到的 Q/K 空间中，不等于人工词典中的“语义相似度”。

## 常见误解

- **“Attention 先选出唯一相关 Token。”** 它通常先给多个位置不同分数。
- **“某个 Token 有固定重要性。”** 分数取决于特定 Query 与 Key 的关系。
- **“点积是在比较原始文字。”** 它比较模型内部的 Q/K 向量。
