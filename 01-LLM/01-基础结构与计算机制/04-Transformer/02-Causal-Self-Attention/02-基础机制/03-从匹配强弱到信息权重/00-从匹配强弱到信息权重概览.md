# 从匹配强弱到信息权重

> [!summary]
> 模型先比较当前位置与各个可见位置的匹配强弱，再排除禁止读取的位置，最后把剩余分数整理成用于获取信息的相对权重。

## 基础机制路线

```text
当前位置分别比较其他位置
→ 得到未经整理的匹配强弱 Score
→ 排除未来等禁止位置
→ 把剩余 Score 转换成相对 Weight
→ 下一步使用 Weight 汇总 Value
```

点积、`√head_dim`、Softmax 公式和矩阵形状都放在各篇的“可选技术补充”，不是理解主线的前置条件。
