# Q、K、V 怎样由线性投影产生

> [!summary]
> 同一份 Hidden State 会经过三种不同的可学习变换，分别得到 Q、K、V；三种结果来自同一位置，但承担不同角色。

## 必读：先理解发生了什么

每个位置原本只有一份 Hidden State。模型需要把它转换成三种用途：

```text
当前位置的 Hidden State
├→ Q 投影 → 用于发起匹配
├→ K 投影 → 用于接受匹配
└→ V 投影 → 用于提供内容
```

“投影”可以先理解为：模型使用一组训练得到的权重，重新组合输入向量中的信息，生成另一组向量。

## 为什么不能只是复制三份

如果只复制三份，Q、K、V 的数字完全相同，模型就无法分别学习：

```text
怎样寻找信息
怎样被其他位置找到
找到后提供什么信息
```

三种投影使用不同权重，因此能从同一 Hidden State 中提取适合不同职责的表示。

## 参数和当前结果要分开

```text
投影权重
→ 模型长期保存的参数

Q、K、V
→ 当前输入经过投影后产生的临时向量
```

因此需要区分“产生表示的规则”和“按规则产生的结果”：投影权重定义变换规则，Q、K、V 则是某次前向计算中的结果，不会成为新的模型权重。

## 每个位置都会产生三种表示

输入有三个位置时，可以先这样想：

```text
位置 0 → Q₀、K₀、V₀
位置 1 → Q₁、K₁、V₁
位置 2 → Q₂、K₂、V₂
```

这仍然保留三个位置，只是每个位置获得了三种角色表示。

## 多头边界

真实模型通常同时产生多个 Attention Head 的 Q、K、V。MHA、GQA 和 MQA 对 K/V Head 的共享方式不同，因此真实张量形状不应在这里统一写死；相关内容留到[[Multi-Head-Attention概览|Multi-Head Attention]]和[[MHA-GQA与MQA概览|MHA、GQA 与 MQA]]。

## 可选技术补充：公式与形状

如果希望知道程序中怎样表示，可以再看这一节。

对单个位置的输入向量 `x`，常简写为：

```text
q = xW_Q
k = xW_K
v = xW_V
```

`W_Q`、`W_K`、`W_V` 是三组不同的参数。

单头教学示例：

```text
输入 X：[3, 4]
投影 W_Q：[4, 2]
输出 Q：[3, 2]
```

它只表示：3 个位置中，每个位置从 4 维输入得到一个 2 维 Query。K、V 可做类似理解。数字是形状示意，不代表所有真实模型。

## 常见误解

- **“Q、K、V 是三组模型参数。”** 投影权重是参数，Q/K/V 是当前计算结果。
- **“投影就是把输入复制三次。”** 不同权重产生不同角色表示。
- **“每个句子只产生一组 Q、K、V。”** 每个位置、每个相关 Head 都会产生对应表示。
- **“必须先会矩阵乘法才能理解 Q、K、V。”** 主线只需理解三种可学习变换和角色分工。
