# 1.1.1 Token

> [!summary]
> Token 是具体 Tokenizer 用来表示文本的离散单位。它不是固定意义上的“字”或“单词”，也还不是模型计算使用的向量。

## 本节只回答三个问题

1. [[1.1.1.1-为什么模型需要Token|为什么模型需要 Token]]：为什么字符串不能直接成为神经网络输入？
2. [[1.1.1.2-Token到底是什么|Token 到底是什么]]：Token、Token ID 和向量怎样区分？
3. [[1.1.1.3-Token可能对应哪些文本单位|Token 可能对应哪些文本单位]]：字、词、子词、字节和特殊 Token 怎样区分？

## 一条主线

```text
开放而可变的文本
→ 切成有限词表可以表示的 Token 序列
→ 每个 Token 再映射成 Token ID
```

本节停在 Token 这一对象本身。词表和编号进入 [[1.1.2-Vocabulary与Token ID概览]]；BPE 等切分方法进入 [[1.1.4-词表构建与切分方法概览]]。
