# 1.5 Output Layer 输出层

> [!goal]
> 理解最后一层 Hidden State 怎样被转换成词表中每个 Token 的分数与概率分布，并明确模型输出概率和运行时选择 Token 的边界。

## 主线

```text
Final Hidden State
→ LM Head
→ vocab_size 个 Logits
→ Softmax
→ 词表概率分布
```

## 计划子结构

1. `1.5.1` Final Hidden State：输出层接收什么；
2. `1.5.2` LM Head：怎样映射到词表宽度；
3. `1.5.3` Logits：尚未归一化的候选分数；
4. `1.5.4` Softmax 与词表概率；
5. `1.5.5` Next Token Prediction 的准确含义与边界。

关键名词将分别建立原子笔记，不把它们挤在一篇长文中。

## 简单数字预览

假设玩具词表只有 4 个 Token：

```text
Logits：      [2.0, 1.0, 0.0, -1.0]
Softmax 后：  [0.64, 0.24, 0.09, 0.03]  （近似示意）
```

这里只需理解：Logit 越高，通常对应更高概率；概率总和为 1。指数函数和推导放在可选部分。

## 阶段边界

Output Layer 到“概率分布”结束。Temperature、Top-k、Top-p、采样、停止条件和逐 Token 循环属于普通运行与生成模块，不放在这里。
