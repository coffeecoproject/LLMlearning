# LLM 基础结构与计算机制大纲

## 本部分回答什么

> 一段文本怎样依次变成 Token ID、向量、上下文表示，最后形成下一个 Token 的词表概率？

这里研究模型的五个核心结构和一次前向计算。完整逐 Token 生成属于“普通运行与生成”，参数怎样更新属于“训练与对齐”。

## 五部分主线

```text
1.1 Tokenizer
文字 → Token → Token ID
        ↓
1.2 Embedding
Token ID → 初始向量
        ↓
1.3 Position
让后续计算利用顺序与距离
        ↓
1.4 Transformer
多层更新上下文相关 Hidden State
        ↓
1.5 Output Layer
Final Hidden State → Logits → 词表概率
```

这是一条学习主线，不代表所有模型实现都把 Position 作为 Embedding 后面的独立代码步骤。RoPE 作用在 Transformer 内部的 Q/K，ALiBi 作用在 Attention Score；把 Position 单列是为了先讲清职责。

## 1.1 Tokenizer 文本离散化系统

> [!map]
> [[1.1-Tokenizer文本离散化系统概览|进入 Tokenizer 专题]]

核心问题：开放文本怎样转换成有限词表中的稳定整数序列？

```text
Tokenizer
├── Token
├── Vocabulary 与 Token ID
├── Word / Character / Subword / Byte 表示路线
├── BPE / WordPiece / Unigram 方法
├── Encode 与 Decode 流程
├── 工具与实现（可选）
└── 影响与边界
```

必须分清：Token 是离散符号，Token ID 是索引，Embedding 才是向量。

## 1.2 Embedding 向量表示

> [!map]
> [[1.2-Embedding向量表示概览|进入 Embedding 专题]]

核心问题：Token ID 已经是数字，为什么还要查表得到向量？

```text
Embedding
├── 向量、维度与张量的最低必要知识
├── Token Embedding
│   ├── Embedding Matrix
│   ├── Embedding Lookup
│   └── 形状与参数量
├── Embedding 参数与语义边界
└── 初始表示与 Hidden State
```

简单数学只使用类似下面的形状与乘法：

```text
vocab_size=5，hidden_size=3
→ Embedding Matrix：[5,3]
→ 参数数：5×3=15
```

## 1.3 Position 位置机制

> [!map]
> [[1.3-Position位置机制概览|进入 Position 专题]]

核心问题：相同 Token 出现在不同顺序和距离时，模型怎样区分？

```text
Position
├── 为什么必须表示顺序
├── Absolute Position Embedding
├── RoPE
├── ALiBi
└── 三类机制的作用位置对比
```

必须分清：Position 决定怎样利用顺序和距离；Causal Mask 决定哪些位置有读取权限。

## 1.4 Transformer

> [!map]
> [[1.4-Transformer概览|进入 Transformer 专题]]

核心问题：每个 Token 位置怎样吸收上下文并逐层形成新的 Hidden State？

```text
Transformer
├── 1.4.1 整体结构
├── 1.4.2 Causal Self-Attention
│   ├── Q、K、V
│   ├── Score、Scaling、Mask、Weight
│   ├── Value 加权与 Context Mixing
│   ├── Multi-Head Attention
│   └── MHA / GQA / MQA
├── 1.4.3 Residual 与 Normalization
│   ├── Residual Connection
│   ├── LayerNorm / RMSNorm
│   └── Pre-Norm / Post-Norm
├── 1.4.4 FFN / MLP
│   ├── 升维、非线性与降维
│   └── SwiGLU / GeGLU
└── 1.4.5 Block 堆叠与 Hidden State 流动
```

Attention 是 Transformer 的子系统，不等于整个 Transformer。

## 1.5 Output Layer 输出层

> [!map]
> [[1.5-Output-Layer输出层概览|进入 Output Layer 专题]]

核心问题：模型怎样把最后的上下文表示转换成整个词表的候选概率？

```text
Output Layer
├── Final Hidden State
├── LM Head
├── Logits
├── Softmax
├── Vocabulary Probability Distribution
└── Next Token Prediction 的准确含义
```

Output Layer 到概率分布为止。Temperature、Top-k、Top-p、采样和逐 Token 循环进入普通运行模块。

## 参数放在哪里

不再单独建立“参数体系”作为第六条并列主线。参数属于各组件：

```text
Embedding 参数 → 1.2
Attention 投影参数 → 1.4.2
Norm 参数 → 1.4.3
FFN 参数 → 1.4.4
LM Head 参数 → 1.5
```

模型总参数量与配置阅读可以在五部分结束后做汇总；Scaling Law 属于评估优化与模型演进，不塞进基础结构。

## 每篇笔记的统一讲法

关键名词单独成篇，并尽量包含：

1. 一句话理解；
2. 为什么需要；
3. 输入和输出；
4. 一个具体例子；
5. 真实机制；
6. 与相邻概念的区别；
7. 简单数字或形状示例；
8. 常见误解；
9. 理解检查；
10. 可选技术深入。

数学只服务于机制理解，不让公式成为主线前置条件。所有虚构 Token、ID、向量和概率都必须明确标注为教学示意。
