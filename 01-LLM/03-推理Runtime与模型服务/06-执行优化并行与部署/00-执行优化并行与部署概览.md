# 执行优化、并行与部署概览

> [!summary]
> 当一个模型或请求无法由单个设备高效承载时，Runtime 可以改变数据精度、计算组织和设备分工；这些方法主要改变速度、容量和成本，不会自动改变模型已经学到的知识。

## 本专题回答什么

```text
模型放不进一个设备怎么办？
→ 量化、设备放置或跨设备拆分

单个Decode步骤没有充分利用硬件怎么办？
→ Batch、优化算子或其他执行策略

一台机器仍然不够怎么办？
→ 多卡或多机部署
```
