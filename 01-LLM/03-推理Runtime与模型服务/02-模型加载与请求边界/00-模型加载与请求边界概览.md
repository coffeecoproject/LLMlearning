# 模型加载与请求边界概览

> [!summary]
> Runtime 在真正计算前，需要把模型配置、权重、Tokenizer 和生成配置装配成可执行对象，并把外部请求转换成一次模型调用所需的输入与状态。

## 计划内容

1. 权重文件、模型配置和 Tokenizer 配置各自是什么；
2. 模型加载与一次请求执行有什么区别；
3. CPU、GPU、显存和设备放置的直白理解；
4. 推理引擎、模型服务器、API 网关和客户端的边界；
5. 本地 Runtime 与托管模型服务能观察到的信息差异。

这里不重复 Tokenizer 的切分机制，只研究 Runtime 怎样装配和调用配套组件。
