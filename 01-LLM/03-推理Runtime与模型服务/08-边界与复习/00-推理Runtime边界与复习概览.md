## 一条最终复习主线

```text
模型资产
→ Runtime启动并加载模型
→ 模型服务器进入Ready
→ 多个请求到达并建立独立状态
→ 调度器动态组成Batch
→ KV Cache Manager分配和回收缓存
→ Runtime执行Prefill与多轮Decode
→ 模型服务器封装响应与Streaming事件
→ 客户端或Agent继续使用结果
```

这条路径把“模型怎样计算”和“系统怎样提供服务”连接起来，但不会把 Runtime 误认为 Agent，也不会把 API 行为误认为服务端内部实现证据。
