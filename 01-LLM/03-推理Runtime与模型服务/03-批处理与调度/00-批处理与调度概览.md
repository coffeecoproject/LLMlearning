# 批处理与调度概览

> [!summary]
> Batch 把多个可一起执行的序列组织成一轮计算；Continuous Batching 则允许 Runtime 随请求到达和结束动态调整正在服务的序列集合。

## 计划内容

1. 输入张量的 Batch 维度与服务端请求 Batch 有什么关系；
2. 静态 Batch 为什么会被最长序列拖累；
3. Prefill 和 Decode 请求为什么具有不同计算特征；
4. Continuous Batching 怎样让已完成请求退出、新请求加入；
5. 调度怎样在吞吐量、公平性和延迟之间权衡。

> [!warning] 核心边界
> 多个请求可以并行组成 Batch，但一个请求内部彼此依赖的未来 Token 仍不能普通地同时确定。
