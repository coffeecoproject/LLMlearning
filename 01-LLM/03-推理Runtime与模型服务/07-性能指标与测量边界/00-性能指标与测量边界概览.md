# 性能指标与测量边界概览

> [!summary]
> Runtime 性能不能只用“每秒多少 Token”概括；用户等待第一个 Token、阅读后续输出、系统承载并发以及完成整项请求，分别对应不同指标。

> [!phase] 运行阶段：模型服务
> 本专题只衡量训练完成后的服务表现，不评价模型训练得是否充分。

## 这一章不要求什么

必读内容不要求计算硬件峰值、显存带宽或集群容量。权重、激活、工作区和 KV Cache 的资源构成只在 Benchmark 条件中作选读提醒；需要做真实部署时再进入工程计算。

## 一句话地图

```text
提交请求
→ 排队
→ Prefill
→ 第一个输出Token      看TTFT
→ 后续输出Token        看ITL或TPOT
→ 最后一个输出完成     看端到端延迟

许多请求共同运行       看吞吐量、并发、成功率和分位数
```
