# 模型加载与请求生命周期概览

> [!summary]
> Runtime 先把磁盘上的模型资产变成可执行的模型服务；服务就绪后，每个请求再经历接收、准备、Prefill、Decode、返回和结束。模型加载与请求运行发生在两条不同的时间线上。

## 本专题先回答什么

```text
模型文件为什么不能自己回答问题？
→ Runtime必须先读取配置、建立结构并加载权重

模型加载完成后，每个用户还要做什么？
→ 为当前请求准备输入和临时状态，再调度模型计算
```

## 两条必须分开的时间线

```text
【服务启动阶段】
读取模型配置与权重
→ 准备Tokenizer等配套资产
→ 把计算放到可用设备
→ 服务进入可接收请求状态

【请求生命周期】
请求到达
→ 校验和准备输入
→ 创建请求状态
→ 调度Prefill与Decode
→ 返回结果
→ 释放或按策略保留状态
```
