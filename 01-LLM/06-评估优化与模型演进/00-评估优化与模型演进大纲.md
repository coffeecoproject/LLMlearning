# 评估、优化与模型演进大纲

> 本部分最后学习怎样定义评估对象、取得可信证据、优化训练或运行效率，以及理解架构演进；训练优化、质量优化和推理优化分开组织。

1. 评估对象、任务定义、指标、基线与通过标准；
2. 自动评测、人工评测与 LLM-as-a-Judge：各自能证明什么；
3. Benchmark 的价值、数据污染、过拟合与版本失真；
4. 能力、事实可靠性、校准、安全性、鲁棒性与领域评估；
5. 模型比较与选择：固定 Prompt、解码参数、模型版本和预算；
6. 数据、训练、Prompt、RAG 与解码层面的质量优化边界；
7. 训练质量、训练稳定性、计算效率与 Scaling；
8. 推理效率：首 Token 延迟（TTFT）、每输出 Token 延迟（TPOT）、吞吐、显存、上下文长度、能耗与成本；
9. 量化、剪枝、蒸馏与模型压缩；
10. Dense、专家混合（MoE）、MHA / GQA / MQA / MLA 与长上下文结构演进；
11. 多模态、推理模型、多 Token 预测（MTP）与投机解码等扩展路线；
12. 开放权重与闭源模型生态、证据等级、未知信息和当前开放问题。

## 评估记录的最低要求

```text
模型与精确版本
+ Prompt / Chat Template
+ 数据集版本与样本范围
+ 解码参数
+ 运行环境与资源预算
+ 指标计算方法
+ 重复次数或不确定性
→ 才构成可比较结果
```

排行榜分数不能自动证明真实任务效果；公开测试集还要额外检查训练数据污染和针对 Benchmark 的过拟合风险。
